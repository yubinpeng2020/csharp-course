  • 取余运算：求除法后的余数，如 10 % 3 = 1

整数除法的陷阱

  • ⚠️ 整数 ÷ 整数 = 整数（截断小数部分）
CSHARP
  int a = 5 / 2;     // a = 2，不是2.5！
  int b = 10 / 3;    // b = 3
  • 想要小数结果 → 至少有一个操作数是小数：
CSHARP
  double c = 5.0 / 2;    // c = 2.5 ✅
  double d = 5 / 2.0;    // d = 2.5 ✅
  double e = (double)5 / 2;  // e = 2.5 ✅ 先把5强制转为5.0，再除以2
因为 int 类型只能存储整数。两个 int 做除法时，C# 按照整数除法规则，结果也是 int，小数部分直接被丢弃（不是四舍五入）。这和数学里的除法不一样，是编程语言的设计规则。

自增自减

运算符名称等价于
x++后置自增先用x，再加1
++x前置自增先加1，再用x
x--后置自减先用x，再减1
--x前置自减先减1，再用x
  • 前置 vs 后置的区别：
CSHARP
  int a = 5;
  int b = a++;   // b = 5, a = 6  (先把a的值5赋给b，a再加1)
  int c = ++a;   // c = 7, a = 7  (a先加1变成7，再把7赋给c)

  int d = 5;
  int e = d--;   // e = 5, d = 4  (先把d的值5赋给e，d再减1)
  int f = --d;   // f = 3, d = 3  (d先减1变成3，再把3赋给f)

课堂练习1 — 算术运算

动手算几道算术题，同时观察整数除法和自增自减的效果。

代码示例（老师示范讲解）

CSHARP
int a = 10, b = 3;

Console.WriteLine($"a + b = {a + b}");   // 13
Console.WriteLine($"a - b = {a - b}");   // 7
Console.WriteLine($"a * b = {a * b}");   // 30
Console.WriteLine($"a / b = {a / b}");   // 3（整数除！）
Console.WriteLine($"a % b = {a % b}");   // 1

int x = 5;
Console.WriteLine($"x++ = {x++}");       // 输出5，x变成6
Console.WriteLine($"++x = {++x}");       // x从6变成7，输出7
  • 动手：修改a和b的值，观察输出变化
💬 解释说明
  • 整数除法 10 / 3 = 3，小数部分被截断，不会四舍五入
  • x++ 先用后加，++x 先加后用
  • 取余 % 是求余数，不是百分比

关系运算符

运算符说明示例（结果）
==等于5 == 5 → true
!=不等于5 != 3 → true
>大于5 > 3 → true
<小于5 < 3 → false
>=大于等于5 >= 5 → true
<=小于等于5 <= 3 → false
  • 比较结果一定是 bool 类型（true/false）
  • ⚠️ 等于用 ==（两个等号），一个 = 是赋值
CSHARP
  int age = 18;
  bool isAdult = (age >= 18);   // true
  bool isTen = (age == 10);     // false

逻辑运算符

运算符说明示例
&&与（两个条件都满足）age >= 18 && age <= 60
||或（满足一个即可）score < 0 || score > 100
!非（取反）!isPass

ABA && BA || B!A
truetruetruetruefalse
truefalsefalsetruefalse
falsetruefalsetruetrue
falsefalsefalsefalsetrue

短路特性

  • &&：如果左边为 false，右边不再计算（因为结果一定是 false）
CSHARP
  int a = 0;
  bool r = (a > 10) && (a++ > 0);  // a++ 不会执行！a仍为0
  • ||：如果左边为 true，右边不再计算（因为结果一定是 true）
CSHARP
  int b = 5;
  bool r = (b > 0) || (b++ > 10);  // b++ 不会执行！b仍为5
  • ⚠️ 短路特性可能导致后面的表达式不执行，要注意
"短路"像智能开关——&& 左边为 false 时，右边就不看了（反正结果一定是 false）；|| 左边为 true 时，右边也不看了。好处是提升效率，但也可能让后面的 a++、b++ 被跳过，写代码时要小心。

位运算符

  • 位运算直接操作二进制位，用于底层优化
运算符名称规则示例
&位与两1才16 & 11 → 00000110 & 00001011 = 2
|位或有1则16 | 11 → 00000110 | 00001011 = 15
^位异或不同为16 ^ 11 → 00000110 ^ 00001011 = 13
~位非取反~6 → ~00000110 = -7
<<左移左移n位3 << 2 = 12（3×4）
>>右移右移n位12 >> 2 = 3（12÷4）
  • 左移1位 = 乘以2，右移1位 = 除以2（比 * / 更快）
  • 日常编程很少用到位运算，了解即可

课堂练习2 — 条件判断

用关系运算符判断分数是否及格，再用逻辑运算符组合多个条件判断天气。

代码示例（老师示范讲解）

CSHARP
int score = 85;

bool isPass = (score >= 60);
Console.WriteLine($"及格：{isPass}");

bool isExcellent = (score >= 90);
Console.WriteLine($"优秀：{isExcellent}");

// 组合条件：判断是否在有效范围
bool isValid = (score >= 0) && (score <= 100);
Console.WriteLine($"分数有效：{isValid}");

// 判断是否不及格或超高分
bool needCheck = (score < 60) || (score > 100);
Console.WriteLine($"需要关注：{needCheck}");
  • 动手：把 score 改成 95、55、-10，观察每个 bool 值的变化
💬 解释说明
  • && 两边都 true 才为 true，|| 一边 true 就为 true
  • ! 取反：!true → false

练习（动手写）

补全下面代码，判断一个数是否在 1~100 之间：

CSHARP
int n = 50;
bool inRange = (n ___ 1) ___ (n ___ 100);
Console.WriteLine($"n在有效范围：{___}");
CSHARP
int n = 50;
bool inRange = (n >= 1) && (n <= 100);
Console.WriteLine($"n在有效范围：{inRange}");

三元运算符（?:）

  • 格式：条件 ? 结果1 : 结果2
  • 如果条件为 true → 返回结果1；否则 → 返回结果2
CSHARP
  int score = 75;
  string result = (score >= 60) ? "及格" : "不及格";
  // result = "及格"

  int a = 10, b = 20;
  int max = (a > b) ? a : b;
  // max = 20
  • 三元运算符是 if-else 的简写版（if-else 下个课件讲）

运算符优先级

  • 当多个运算符同时出现，计算顺序按优先级：
优先级运算符
高() 括号
↑++ -- !（一元）
* / %
+ -
< > <= >=
== !=
&&
↓||
低= += -= 等（赋值）
  • 记不住就用括号，括号里优先计算：
CSHARP
  int r1 = 2 + 3 * 4;      // 14（先乘后加）
  int r2 = (2 + 3) * 4;    // 20（括号优先）
用括号！括号内的永远先算，加了括号代码也更清晰。2 + 3 × 4 不如 2 + (3 × 4) 一眼看得懂。考试可能让你背，写代码时用括号就行。

本节知识梳理

今天我们一起啃下了这些核心内容：

  • 算术运算符：+ - * / %，% 取余数
  • 自增自减：i++ / i--，用前用后取值不同
  • 赋值运算符：= 及其复合写法 += -= *= /=
  • 关系运算符：> < >= <= == !=，结果都是 bool
  • 逻辑运算符：&& 与、|| 或、! 非，用来组合条件
  • 位运算符：& | ^ ~ << >>，直接对二进制位操作
  • 三元运算符（?:）：条件 ? 真值 : 假值，一行代替简单 if-else
  • 运算符优先级：先乘除后加减，有括号先算括号
💡 接下来是「综合练习」——不再是单个知识点的小练习，而是把上面这些串起来解决一个真实小任务。先自己动手写，实在卡住再看答案。

综合练习 — 简易计算器

实现一个简易计算器：输入两个数和运算符，输出计算结果。

期望输入： 交互输入（见运行效果）

期望输出：

请输入第一个数字：10
请输入运算符（+、-、*、/）：*
请输入第二个数字：3
10 * 3 = 30
  • 用 double.Parse() 把输入转成数字
  • 用 if (op == "+") / else if (op == "-") 等判断运算符
  • ___ 是需要你补全的地方

练习

请在下面的模板中补全空白（___）：

if (op ___ "+") result = num1 + num2;
else if (op == "-") result = ___;
else if (op == "*") result = num1 * num2;
else if (op == "/") result = ___;
else valid = false;

    Console.WriteLine($"{num1} {op} {num2} = {___}");

    Console.WriteLine("运算符无效！");
CSHARP
Console.Write("请输入第一个数字：");
double num1 = double.Parse(Console.ReadLine());

Console.Write("请输入运算符（+、-、*、/）：");
string op = Console.ReadLine();

Console.Write("请输入第二个数字：");
double num2 = double.Parse(Console.ReadLine());

double result = 0;
bool valid = true;

if (op == "+") result = num1 + num2;
else if (op == "-") result = num1 - num2;
else if (op == "*") result = num1 * num2;
else if (op == "/") result = num1 / num2;
else valid = false;

if (valid)
    Console.WriteLine($"{num1} {op} {num2} = {result}");
else
    Console.WriteLine("运算符无效！");

拔高题（选做，自己写，不填空）

需求：让用户输入一个年份，判断是否为闰年并输出结果。
闰年规则：能被 4 整除且不能被 100 整除，或者能被 400 整除。
要求：用逻辑运算符 &&、||、! 和取余 % 自己写判断，不能用现成模板。
提示：(year % 4 == 0 && year % 100 != 0) || year % 400 == 0
CSHARP
int year = int.Parse(Console.ReadLine());
bool isLeap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
Console.WriteLine(isLeap ? $"{year} 是闰年" : $"{year} 不是闰年");
