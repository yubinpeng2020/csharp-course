从控制台到窗体

之前写的是"黑框打字"，今天起写的是"能点的窗口"。
对比维度控制台程序窗体程序（Avalonia）
用户界面黑底白字命令行图形化窗口（用 XAML 描述）
交互方式键盘输入 → 文字输出鼠标点击、输入框、按钮
程序结构顺序执行：一行接一行，卡在 ReadLine 等输入事件驱动：用户操作才触发对应代码
典型代码Console.ReadLine()Click="方法名"（在 XAML 里关联）

一句话抓住本质

窗体程序就两件事：摆控件 + 写事件——先在窗口上摆好按钮、文本框，再告诉程序"用户点了按钮，就执行这段代码"。

💡 记住套路：控件 + 事件。后面每一页都在这套路上加东西，看懂这一页就不慌。

跨平台与 Avalonia

一句话：Avalonia 让你"写一次界面，Windows / macOS / Linux 都能跑"。

什么是"跨平台"

  • 同一份代码，不用大改，就能在不同操作系统上运行
  • 桌面系统：Windows、macOS、Linux
  • 移动系统：iOS、Android
  • 网页 Web：WebAssembly（浏览器里直接跑）
  • 好处：少写几套代码、你用自己的电脑（Win 或 Mac）都能跑本课例子
💡 Avalonia 的"门槛"极低：只要一个平台能"画像素"还能"收输入"，就能跑 Avalonia——所以它从桌面一路覆盖到手机、网页甚至嵌入式设备。

Avalonia 是什么

  • 开源的跨平台 UI 框架，用 .NET + C# + XAML 描述图形界面
  • 它自带渲染引擎（基于 Skia）自己画控件，不依赖系统原生控件，所以界面在哪儿都长得一模一样
  • 对比另一个跨平台框架 MAUI：MAUI "包装"各系统的原生控件（外观随系统变），Avalonia "自己画"（外观完全统一）——本课选它，正是看中跨平台一致、老师 Mac 也能演示
  • 和你们听过的 WinForms 是"同类"（画窗口、摆控件），但 WinForms 只能在 Windows 跑

为什么本课选 Avalonia（而不是 WinForms / MAUI）

WinFormsMAUIAvalonia
能跑的系统仅 Windows桌面 + 手机桌面 + 手机 + Web 等
界面实现系统原生控件包装系统原生控件自绘（Skia，外观统一）
老师能否 Mac 演示不行可（但偏重）可以 ✅
💡 官方一句话："一个代码库，无限可能"（One codebase, endless possibilities）。记住：Avalonia = 跨平台的"WinForms 升级版"，后面学的"控件 + 事件"套路和它几乎一样。

创建第一个 Avalonia 项目

不需要 Visual Studio，任意装了 .NET SDK 的电脑（含 Mac）都能做：

  1. 安装模板：dotnet new install Avalonia.Templates
  2. 新建项目：dotnet new avalonia.app -o 我的窗体（生成一个 Avalonia 跨平台项目）
  3. 用 VS Code 打开（装 Avalonia 预览扩展后，写 XAML 能实时看到窗口样子；Mac 也能用）
📋 模板怎么选（先 dotnet new list 查看可用模板）：Avalonia 主要有三个——
- avalonia.app —— 纯 Code-behind（XAML + 事件代码），本课用它，最简单
- avalonia.mvvm —— 带 MVVM 分层架构，适合大项目，但入门偏复杂
- avalonia.xplat —— 额外含 Web / 手机平台，本项目用不到注：官方文档推荐 avalonia.mvvm + JetBrains Rider，并不推荐 VS Code；但学校机房用 VS Code 免费、Mac 也能跑，入门更现实，所以本课选 avalonia.app + VS Code。

生成的关键文件：

MainWindow.axaml     ← 界面（XAML 描述：窗口里有什么控件）
MainWindow.axaml.cs  ← 逻辑（C# 代码：按钮点击后做什么）
Program.cs           ← 程序入口（不用改）
App.axaml            ← 全局样式主题（不用改）
💡 和 WinForms 最大区别：没有"拖控件的设计器"，界面是写 XAML 写出来的。但 VS Code 有预览器，改完立刻能看到，并不比拖控件难。

常用控件 — TextBlock / TextBox / Button

⚠️ 和 WinForms 的三个大不同（务必先看）
1. 显示文字用 TextBlock，不是 Label（Label 在 Avalonia 是给别的控件加快捷键的，不用来显示文字）
2. 修改属性名变了：BackColor → Background、Enabled → IsEnabled、ReadOnly → IsReadOnly
3. 没有 MessageBox.Show！要提示用户，用窗口上的 TextBlock 显示文字。本课都用 TextBlock 显示提示

XAML 快速看懂

XAML 是用"标签"描述界面的语言。Avalonia 的文件后缀是 .axaml（不是 .xaml，特意和 WPF 区分开）：

  • 标签名 = 控件类名：<Button> 就是按钮，<TextBox> 就是输入框
  • 标签里的属性 = 控件属性：Background="Blue"、Content="确定" 都是在设属性
  • 标签之间的内容 = 控件的"内容"：<Button>确定</Button> 等价于 Content="确定"
  • 文件开头通常有三个命名空间（xmlns、xmlns:x、x:Class），照模板写即可，不用背
💡 XAML 看着像网页 HTML，但它描述的是一棵"对象树"：每个标签对应一个 C# 对象，属性就是对象的字段。看懂这点，后面换控件只是换标签名。

界面写在 MainWindow.axaml 里，用 StackPanel（竖直排列容器）把控件一个个摞起来：

XML
<StackPanel Margin="20" Spacing="10">
    <TextBlock x:Name="tip" Text="请输入姓名：" />
    <TextBox x:Name="nameBox" Watermark="在这里输入" />
    <Button x:Name="okBtn" Content="确定" Click="OkBtn_Click" />
    <TextBlock x:Name="result" Text="结果会显示在这里" />
</StackPanel>
控件作用常用属性
TextBlock显示提示 / 结果文字Text
TextBox用户输入文字Text、Watermark、IsReadOnly
Button点击执行操作Content（按钮文字）、IsEnabled
  • x:Name="xxx" 相当于给控件起名字，C# 代码里就能直接用 xxx 访问它
  • 不再用"拖控件 + 属性窗口"，而是写 XAML + 布局容器

布局基础 — 控件摆在哪里

控件不能随便乱飘，得放进"布局容器"里，由容器决定它们怎么排列。Avalonia 常用 5 种布局容器：

1. StackPanel —— 摞起来 / 排成行

控件一个接一个竖直（默认）或水平排列，Spacing 控制间距：

XML
<StackPanel Orientation="Vertical" Spacing="10">
    <Button Content="按钮1" />
    <Button Content="按钮2" />
</StackPanel>

2. Grid —— 表格（最灵活）

用 ColumnDefinitions / RowDefinitions 划分行列，* 表示按比例、Auto 表示按内容；再用 Grid.Row / Grid.Column 把控件放进指定格：

XML
<Grid ColumnDefinitions="*,2*" RowDefinitions="Auto,*,100">
    <Button Grid.Row="0" Grid.Column="0" Content="左上" />
    <Button Grid.Row="0" Grid.Column="1" Content="右上" />
</Grid>
💡 * 和 Auto 是 Grid 的灵魂：前者按比例分剩余空间，后者刚好包住内容。

3. DockPanel —— 靠边停靠

子控件用 DockPanel.Dock="Top/Left/Right/Bottom" 贴边；LastChildFill="True" 让最后一个填满剩余区：

XML
<DockPanel LastChildFill="True">
    <Button DockPanel.Dock="Top" Content="顶栏" />
    <Button DockPanel.Dock="Left" Content="侧栏" />
    <TextBlock Text="中间填充区" />
</DockPanel>

4. WrapPanel —— 自动换行

一行放不下就折到下一行，适合放一排小按钮 / 标签。

5. Canvas —— 绝对定位

用 Canvas.Left / Canvas.Top 指定控件精确坐标，适合画图板、自定义布局。

💡 入门先用 StackPanel（竖直摞控件最省心）；要做复杂界面再用 Grid。本课练习基本都用 StackPanel。

事件 — 按钮点击做什么

在 XAML 里用 Click="方法名" 把按钮和代码关联，再到 MainWindow.axaml.cs 里写这个方法：

CSHARP
// MainWindow.axaml 里：<Button x:Name="okBtn" Content="确定" Click="OkBtn_Click" />
// 对应的代码（MainWindow.axaml.cs）：
public void OkBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    // 在这里写点击按钮后执行的代码
}
CSHARP
// 示例：点击按钮，把输入框的内容显示到结果 TextBlock 上
public void OkBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    string name = nameBox.Text;            // 获取输入框内容
    result.Text = $"你好，{name}！";         // 显示到结果 TextBlock
}
  • 事件驱动：程序不按固定顺序执行，用户点什么就触发什么代码
  • Click="OkBtn_Click" 写在 XAML，OkBtn_Click 方法写在 .axaml.cs 里，两者名字要对上

修改控件属性

可以在代码里动态修改属性（注意属性名和 WinForms 不同）：

CSHARP
// 在事件方法中修改控件属性
public void OkBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    // 修改文字 / 禁用按钮
    okBtn.Content = "已点击";
    okBtn.IsEnabled = false;

    // 修改文本框
    nameBox.IsReadOnly = true;             // 设为只读
    nameBox.Background = Brushes.Green;    // 改背景色（需 using Avalonia.Media;）

    // 提示用户：用 TextBlock 显示，而不是 MessageBox
    result.Text = "操作完成！";
}
⚠️ Avalonia 没有 MessageBox.Show。需要弹提示时，就在窗口放一个 TextBlock 把信息显示出来（或用社区包 MessageBox.Avalonia，但本课不要求）。

课堂练习1 — 姓名问候器

用 TextBox 输入姓名，点击按钮后在 TextBlock 显示问候语——掌握 XAML 的 x:Name 和 C# 事件处理。

代码示例（老师示范讲解）

XML
<StackPanel Margin="20" Spacing="10">
    <TextBlock Text="请输入姓名：" />
    <TextBox x:Name="nameBox" Watermark="在这里输入" />
    <Button x:Name="okBtn" Content="确定" Click="OkBtn_Click" />
    <Button x:Name="clearBtn" Content="清空" Click="ClearBtn_Click" />
    <TextBlock x:Name="result" Text="结果会显示在这里" />
</StackPanel>
CSHARP
public void OkBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    string name = nameBox.Text;
    if (string.IsNullOrWhiteSpace(name))
    {
        result.Text = "⚠️ 请输入姓名！";   // 用 TextBlock 提示，没有 MessageBox
        return;
    }
    result.Text = $"你好，{name}！";
}

public void ClearBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    nameBox.Text = "";
    result.Text = "结果会显示在这里";
}
  • 动手：试试空输入直接点"确定"，再看输入"张三"后的结果
💬 解释说明
  • x:Name="nameBox" —— 给 XAML 里的控件起名，C# 代码就能用这个名字访问它
  • Avalonia 没有 MessageBox！要用窗口上的 TextBlock 显示提示文字
  • string.IsNullOrWhiteSpace(name) —— 检查是否为空或全空格，比 name == "" 更安全
  • 事件方法签名固定为 (object? sender, RoutedEventArgs e)，Click="方法名" 会自动关联

练习（动手写）

补全代码，加上"清空"按钮的功能（点击后清空 TextBox 和结果 TextBlock）：

CSHARP
public void ClearBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    nameBox.Text = ___;
    result.Text = ___;
}
CSHARP
public void ClearBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    nameBox.Text = "";
    result.Text = "结果会显示在这里";
}

本节知识梳理

今天我们一起啃下了这些核心内容：

  • 从控制台到窗体：相比黑框，窗体有按钮文字框，交互更直观
  • 跨平台与 Avalonia：一套 C#+XAML 代码，跑到 Windows/mac/Linux/手机/网页
  • 常用控件 — TextBlock / TextBox / Button：显示文字 / 输入文字 / 点击按钮
  • 布局基础 — 控件摆在哪里：StackPanel 竖排横排、Grid 网格定位
  • 事件 — 按钮点击做什么：双击按钮生成 Click 事件，写点击后的逻辑
  • 修改控件属性：代码里改 Text/IsEnabled/Background 等，界面实时变
💡 接下来是「综合练习」——不再是单个知识点的小练习，而是把上面这些串起来解决一个真实小任务。先自己动手写，实在卡住再看答案。

综合练习 — 登录窗口

用户名 + 密码输入，点击登录后验证账号密码——综合运用 TextBox、Button 事件、条件判断和控件属性修改。

期望输入：

用户名：admin
密码：123456
（尝试错误的密码如 111111 —— 应提示错误并清空密码框）

期望输出：

（正确时）✅ 登录成功！（文字变绿）
（错误时）❌ 用户名或密码错误（文字变红，密码框自动清空）
  • PasswordChar="*" —— 让密码框显示为星号，但 Text 属性仍是真实密码
  • 颜色用 Foreground = Brushes.Green，不是 ForeColor
  • ___ 是需要你补全的地方

练习

请在下面的模板中补全空白（___）：

XML
<StackPanel Margin="20" Spacing="10">
    <TextBox x:Name="userBox" Watermark="用户名" />
    <TextBox x:Name="passBox" Watermark="密码" PasswordChar="___" />
    <Button x:Name="loginBtn" Content="登录" Click="LoginBtn_Click" />
    <TextBlock x:Name="result" />
</StackPanel>
CSHARP
public void LoginBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    string user = userBox.Text;
    string pass = passBox.Text;

    if (___ == "admin" && pass == "___")
    {
        result.Text = "___ 登录成功！";
        result.___ = Brushes.Green;
    }
    else
    {
        result.Text = "❌ 用户名或密码错误";
        result.Foreground = Brushes.___;
        passBox.Text = ___;          // 清空密码框
        passBox.___();               // 光标回到密码框
    }
}
XML
<StackPanel Margin="20" Spacing="10">
    <TextBox x:Name="userBox" Watermark="用户名" />
    <TextBox x:Name="passBox" Watermark="密码" PasswordChar="*" />

public void LoginBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    string user = userBox.Text;
    string pass = passBox.Text;

    if (user == "admin" && pass == "123456")
    {
        result.Text = "✅ 登录成功！";
        result.Foreground = Brushes.Green;
    }
    else
    {
        result.Text = "❌ 用户名或密码错误";
