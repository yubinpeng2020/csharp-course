为什么需要类？

前面学了变量、数组、集合——数据越存越多，但它们散落在 Main 里互不关联。一个学生有姓名、年龄、成绩，这三块数据本该属于同一个整体——这节课学类，把数据和功能打包到一起。

到目前为止写的代码，变量和逻辑全塞在 Main 里——系统小还能撑，一旦系统变大，Main 就变成了几百行的"垃圾堆"：想改个东西得翻半天，想复制一段逻辑到处粘贴，多人合作更是灾难。

更致命的是，现实中的"东西"（比如学生）天然带着数据和功能——不说类的话，就得：

CSHARP
string name1 = "张三"; int age1 = 18; double score1 = 85;
string name2 = "李四"; int age2 = 19; double score2 = 90;
// 如果100个学生……直接崩溃

类的解决方案：把相关数据和功能打包在一起，一个"学生类"就管学生的事，清晰、可复用、不互相打架。

类 = 蓝图，对象 = 实例

还记得课件3的变量盒子吗？类就是它的升级版——一个大盒子，里面打包了多个变量盒子 + 配套的操作：

┌─────────── 类：Person（蓝图/模板）──────────┐
│                                             │
│  📦 字段（数据 — 人的属性）                    │
│  ┌──────┐ ┌──────┐ ┌──────────┐             │
│  │name  │ │ age  │ │ height   │             │
│  │string│ │ int  │ │ double   │             │
│  └──────┘ └──────┘ └──────────┘             │
│                                             │
│  ⚙️ 方法（行为 — 人能做什么）                   │
│  ┌──────────────────────┐                   │
│  │ SayHello()  打招呼    │                   │
│  │ Grow()      长大一岁  │                   │
│  └──────────────────────┘                   │
│                                             │
└─────────────────────────────────────────────┘
         │                    │
         ▼                    ▼
┌──────────────┐     ┌──────────────┐
│ Person s1    │     │ Person s2    │
│ name："张三"  │     │ name："李四"  │
│ age：18      │     │ age：19      │
│ height：1.75 │     │ height：1.68 │
│              │     │              │
│ s1.SayHello()│     │ s2.SayHello()│
│ s1.Grow()    │     │ s2.Grow()    │
└──────────────┘     └──────────────┘
   ▲ 同一个模板，不同的数据                   ▲
  • 类就像一个大盒子框架，里面分成两格：一格装数据（字段），一格装功能（方法）
  • 用 new 创建对象时，就从这个框架"复印"出一份——每个对象字段值自己填，方法共用同一套

生活中的类比：

比喻类（Class）对象（Object）
手机设计图纸生产出来的真手机（无数部）
饼干模具压出来的饼干（形状相同，馅料不同）
学生表空白登记表模板填好的张三的表、李四的表
盖房户型图纸盖好的房子
  • 类 = 定义了"有什么数据"和"能做什么事"的模板
  • 对象 = 按模板创建的具体实例，每个对象的字段值可以不同

用已学过的类型理解：

CSHARP
int a = 10;          // int 是"类型"，a 是"具体的值"
string s = "hello";  // string 是"类型"，s 是"具体的字符串"

Student s1 = new Student();  // Student 是你定义的"类型"
                             // s1 是"具体的对象"
// s1.name = "张三"          // 每个对象的数据不同

定义第一个类并创建对象

CSHARP
class Person           // class 关键字 + 类名（Pascal命名规范）
{
    // 字段 = 人的特征（数据）
    public string name;     // 姓名
    public int age;         // 年龄
    public double height;   // 身高

    // 方法 = 人的行为（能做什么事）
    public void SayHello()  // 打招呼
    {
        Console.WriteLine($"你好，我叫{name}，今年{age}岁");
    }

    public void Grow()      // 长大一岁
    {
        age++;
        Console.WriteLine($"{name}长大了一岁，现在{age}岁");
    }
}

类的定义写好了，怎么用？标准写法跟声明变量很像：

CSHARP
// 变量的标准写法             创建对象的标准写法
int age = 18;                Person p1 = new Person();
//   ↑类型  ↑变量名  ↑值       ↑类型  ↑对象名  ↑new 创建实例

new 关键字——把蓝图变成现实

new 你其实已经用过了——new int[5] 是在内存里分配一个数组。现在 new Person() 是分配一个 Person 对象的"家"：

  • new = 在内存中开辟一块空间，按类的模板把字段和方法装进去
  • 没有 new，类只是图纸；有了 new，才拿到一个可以操作的真实对象
CSHARP
// 用 new 关键字创建对象（按图纸生产一部新手机）
Person p1 = new Person();
p1.name = "张三";
p1.age = 18;
p1.height = 1.75;
p1.SayHello();  // 你好，我叫张三，今年18岁
p1.Grow();      // 张三长大了一岁，现在19岁

// 同一类可以创建多个对象，数据互不影响
Person p2 = new Person();
p2.name = "李四";
p2.age = 20;
p2.height = 1.80;
p2.SayHello();  // 你好，我叫李四，今年20岁
p1.SayHello();  // 你好，我叫张三，今年19岁 ← p1没变
  • . = 访问对象的成员（字段/方法）
  • 每个对象拥有一套独立的字段值，互不干扰
  • 💬 就像同一份空白表格复印了 100 份，每个人填自己的信息——张三在自己的表上把年龄改成 19 岁，李四表上的年龄纹丝不动。100 个对象 = 100 份独立数据。
  • 💡 对象初始化器：创建对象的同时在 { } 里直接赋值，更简洁
CSHARP
  Person p = new Person { name = "张三", age = 18, height = 1.75 };

方法的参数与返回值

上页我们调用了 SayHello()、Grow() 等方法。这些方法到底是怎么定义出来的？看一个「两数相加」的完整例子：

CSHARP
class Calculator
{
    public int Add(int a, int b)             // 有参数，有返回值
    { return a + b; }

    public void PrintSum(int a, int b)        // 有参数，无返回值
    { Console.WriteLine($"{a} + {b} = {a + b}"); }

    public double GetPi()                     // 无参数，有返回值
    { return 3.14159; }
}

拿 Add 方法拆开看，由五部分组成：

public   int    Add    (int a, int b)   { return a + b; }
  ↑       ↑      ↑          ↑                  ↑
访问修饰符 返回类型 方法名   参数列表（输入）    方法体（做什么）
  • public = 公开的——谁都能调。private/protected 后面课件细讲，目前统一用 public
  • int = 返回类型——方法执行完把什么类型的数据还给调用者。int 还数字，double 还小数，void 表示「不还东西」
  • (int a, int b) = 参数列表——调用时要传的数据，a 和 b 在这方法里当局部变量用
  • { return a + b; } = 方法体——真正干活的代码
方法的公式：public 返回类型 方法名(参数列表) { 方法体 }

调用它的时候：

CSHARP
int result = calc.Add(3, 5);   // 3和5传进去，Add 方法执行，return 8 传出来

void vs 有返回值的区别：

CSHARP
// Add 有 int 返回值 → 可接住，可继续参与运算
int sum = calc.Add(3, 5);
Console.WriteLine(sum + 10);        // 15

// PrintSum 是 void → 没有返回值，没法"接"
calc.PrintSum(3, 5);                // 只能让它直接执行
// int x = calc.PrintSum(3, 5);    // ❌ 编译错误！void 方法不能赋值

四种常见组合：

组合语法示例
有参有返类型 方法(参数) { return 值; }int Add(int a, int b)
有参无返void 方法(参数) { }void PrintSum(int a, int b)
无参有返类型 方法() { return 值; }double GetPi()
无参无返void 方法() { }void SayHello()

课堂练习1 — 学生成绩计算

定义 Student 类，包含语数英字段和计算总分/平均分的方法，创建对象并输出。

代码示例（老师示范讲解）

CSHARP
class Student
{
    public string name;
    public double chinese;
    public double math;
    public double english;

    // 计算总分
    public double GetTotal()
    {
        return chinese + math + english;
    }

    // 计算平均分（方法内部调用另一个方法）
    public double GetAverage()
    {
        return GetTotal() / 3;
    }
}
CSHARP
Student s = new Student();
s.name = "张三";
s.chinese = 85; s.math = 90; s.english = 78;
Console.WriteLine($"{s.name} 总分：{s.GetTotal()}，平均：{s.GetAverage():F1}");
// 张三 总分：253，平均：84.3
  • 动手：把张三的成绩改成你自己的各科分数，看输出变化
💬 解释说明
  • 字段 chinese、math、english 是学生的"数据"，方法 GetTotal()、GetAverage() 是学生的"功能"
  • GetAverage() 内部调用 GetTotal()——方法之间可以互相配合，不用把所有逻辑堆在一个方法里
  • 平均分里 / 3 是硬编码的，更好的写法是用字段个数动态计算

构造方法与 this 关键字

前面写 new Person() 时，对象创建完还得一行行 p.name =、p.age = 赋值。能不能创建时就一步到位？构造方法就是干这个的。

一个构造方法长这样：

public   Person   (string n, int a)   { name = n;  age = a; }
  ↑        ↑             ↑                    ↑
访问修饰符  类名         参数列表             方法体（初始化字段）

构造方法就是特殊的方法，有三个特殊之处：

  • 名字 = 类名：必须和类同名，不是随便起的方法名
  • 没有返回值类型：连 void 都不写（和普通方法的区别）
  • 自动调用：用 new 创建对象时自动执行，不用手动调
CSHARP
class Person
{
    public string name;
    public int age;

    public Person(string n, int a)       // 名字和类名相同，没有返回值类型
    {
        name = n;
        age = a;
    }

    public Person() { }                  // 无参构造（如果没写，系统会默认生成一个空的）
}
CSHARP
// 创建对象时就能直接赋值，不用分行写 name =、age =
Person p1 = new Person("张三", 18);   // 用有参构造，一步到位
Person p2 = new Person();             // 用无参构造，之后手动赋值
p2.name = "李四"; p2.age = 19;

// 对比：没有构造方法时
Person p3 = new Person();
p3.name = "王五"; p3.age = 20;         // 需要3行
  • 构造方法 = 出厂设置，创建对象时自动执行，只执行一次

上面示例用了 string n, int a 当参数名，虽然能跑，但 n、a 看不出含义。更好的写法是把参数名写得和字段名一样——清楚。但问题来了：名字一样，谁来区分？

这时候就要用 this：

CSHARP
class Person
{
    public string name;
    public int age;

    public Person(string name, int age)  // 参数名和字段同名了！
    {
        this.name = name;    // this.name = 字段，= 右边的 name = 参数
        this.age = age;
    }

    public bool IsOlderThan(int age)     // 参数和字段又重名了
    {
        return this.age > age;           // this.age是字段，age是参数
    }
}
  • this = "当前这个对象自己"
  • 当参数名和字段名相同时，this.字段 指向对象的字段，不带 this 的就是参数
  • 💬 就像说自己「我的手机」——"我"就是 this，用来区分是你的还是别人的

本节知识梳理

今天我们一起啃下了这些核心内容：

  • 为什么需要类？：把「数据」和「操作数据的方法」打包，避免散落
  • 类 = 蓝图，对象 = 实例：类定义长什么样，new 出来才是真东西
  • 定义第一个类并创建对象：class 类名{...} + new 类名()
  • 方法的参数与返回值：参数接收输入，return 返回结果
  • 构造方法与 this 关键字：构造方法 类名() 在 new 时自动调用，this 指当前对象

综合练习 — 银行账户

定义 BankAccount 类，实现存钱/取钱功能，取钱时检查余额是否足够。

期望输入： 交互输入（见运行效果）

期望输出：

存入500元，余额：1500

CSHARP
class BankAccount
{
    public string owner;
    private double balance;

    public BankAccount(string owner, double balance)
    {
        this.owner = owner;
        this.balance = balance;
    }

    public void Deposit(double amount)
    {
        balance += amount;
        Console.WriteLine($"存入{amount}元，余额：{balance}");
    }

    public bool Withdraw(double amount)
    {
        if (amount > balance)
        {
            Console.WriteLine("余额不足！");
            return false;
        }
        balance -= amount;
        Console.WriteLine($"取出{amount}元，余额：{balance}");
        return true;
    }
}

acc.Deposit(500);
acc.Withdraw(200);
acc.Withdraw(2000);

拔高题（选做，自己写，不填空）

需求：自己定义一个 Rectangle（长方形）类，含长、宽两个字段，以及计算面积和周长的方法；在 Main 里读入长、宽并调用方法输出。
要求：完整定义类 + Main 调用，不能用现成模板。
CSHARP
class Rectangle
{
    public double Width;
    public double Height;
    public double Area() => Width * Height;
    public double Perimeter() => 2 * (Width + Height);
}
class Program
{
    static void Main()
    {
        Rectangle r = new Rectangle();
        r.Width = double.Parse(Console.ReadLine());
        r.Height = double.Parse(Console.ReadLine());
        Console.WriteLine($"面积={r.Area()}，周长={r.Perimeter()}");
    }
}
