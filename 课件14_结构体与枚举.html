struct 结构体 — 轻量级的"小类"

回顾课件9：值类型是"给你复印件，你改你的我不管"（int、double）；引用类型是"给你门牌号，你按地址改了我也变"（class、数组）。那有没有值类型的"小类"？——结构体 struct。

CSHARP
// 类：引用类型（门牌号）
class PointClass
{
    public int X;
    public int Y;
}

// 结构体：值类型（复印件），写法几乎一样
struct PointStruct
{
    public int X;
    public int Y;
}
CSHARP
PointClass c1 = new PointClass();  c1.X = 10; c1.Y = 20;
PointClass c2 = c1;                 // c2 拿门牌号
c2.X = 99;                          // c1.X 也变 99！⚠️

PointStruct s1 = new PointStruct(); s1.X = 10; s1.Y = 20;
PointStruct s2 = s1;                // s2 拿到复印件
s2.X = 99;                          // s1.X 还是 10 ✅
💬 同样是 = 赋值，结果天差地别：
- c2 = c1（class）→ c2 和 c1 指向同一个对象，改 c2 就是改 c1
- s2 = s1（struct）→ s2 拿到的是全新副本，从此各过各的，互不干扰
- 这就是"门牌号"vs"复印件"在代码里的体现——struct 天然隔离，class 天然共享

结构体 vs 类

类（class）结构体（struct）
类型引用类型值类型
赋值传门牌号，互相影响传复印件，独立
构造方法可有无参构造不能自定义无参构造
继承支持不支持（不能继承）
适用场景复杂对象（学生、账户）简单数据（坐标、颜色）

构造方法的区别：

CSHARP
// class：可以有无参构造
class Student
{
    public Student() { }           // ✅ 允许
    public Student(string name) { }
}

// struct：不能自定义无参构造（编译报错）
struct Point
{
    // public Point() { }          // ❌ 编译错误！
    public Point(int x, int y) { } // ✅ 有参构造可以
}

继承的区别：

CSHARP
// class：可以继承
class Animal { }
class Dog : Animal { }             // ✅ Dog 继承 Animal

// struct：不能继承（编译报错）
struct Color { }
// struct RGB : Color { }          // ❌ 编译错误！struct 不能继承
💡 继承的概念和用法会在课件15重点讲解，这里先记住结论：class 能继承，struct 不能。

什么时候用结构体？

  • 数据量小（几个字段）
  • 赋值后希望独立，不想互相影响——因为 struct 是值类型，赋值=复印：
CSHARP
  Point p1 = new Point { X = 10, Y = 20 };
  Point p2 = p1;          // 复制一份，p2 独立
  p2.X = 99;
  // p1.X 还是 10 ✅ ，p2.X 变成 99
  // 如果是 class，p1.X 也会变成 99 ⚠️
  • 频繁创建销毁，需要高性能

结构体完整示例

💬 来看一个完整的 struct——颜色 Color：有字段（RGB）、有构造方法（必须有参数）、有普通方法（ToHex），和 class 写法几乎一样。唯一不同的是赋值：c2 = c1 是复印而非共享，改一个不动另一个。
CSHARP
struct Color
{
    public int Red;
    public int Green;
    public int Blue;

    // 结构体也可以有构造方法（必须有参数）
    public Color(int r, int g, int b)
    {
        Red = r; Green = g; Blue = b;
    }

    // 结构体也可以有方法
    public string ToHex()
    {
        return $"#{Red:X2}{Green:X2}{Blue:X2}";
    }
}
CSHARP
Color c1 = new Color(255, 87, 51);
Console.WriteLine(c1.ToHex());      // #FF5733

Color c2 = c1;                       // 值类型：独立副本
c2.Red = 0;
Console.WriteLine(c1.ToHex());      // #FF5733（c2改不影响c1）

课堂练习1 — struct 三维坐标

用 struct 定义三维坐标，体会值类型赋值后互不干扰的特点。

代码示例（老师示范讲解）

CSHARP
struct Point3D
{
    public double X;
    public double Y;
    public double Z;

    public Point3D(double x, double y, double z)
    {
        X = x; Y = y; Z = z;
    }

    // 计算到原点的距离
    public double Distance()
    {
        return Math.Sqrt(X * X + Y * Y + Z * Z);
    }
}
CSHARP
Point3D p1 = new Point3D(3, 4, 5);
Console.WriteLine($"p1 到原点距离：{p1.Distance():F2}");   // 7.07

Point3D p2 = p1;                // struct 赋值 = 复印
p2.X = 10;                      // 只改 p2 的 X
Console.WriteLine($"p1.X = {p1.X}");  // 3（没变！）
Console.WriteLine($"p2.X = {p2.X}");  // 10
  • 动手：把 Point3D 改成 class，观察 p1.X 是 3 还是 10
💬 解释说明
  • struct 的 = 是全量复制——p2 拿到 p1 的所有值，从此各过各的
  • 如果是 class，p2 = p1 后改 p2.X 会把 p1.X 也改了——因为共用同一个对象
  • Distance() 演示 struct 里也能写方法，和 class 没区别

enum 枚举 — 给常量取个名字

一周有七天，用 int 表示——0=周一，1=周二……但 day = 8 没人拦。

CSHARP
int day = 8;  // 星期八？编译器一点反应都没有😅

枚举 = 限定取值范围的"选择题"：

CSHARP
enum DayOfWeek
{
    Monday,     // 默认值从 0 开始
    Tuesday,    // 1
    Wednesday,  // 2
    Thursday,   // 3
    Friday,     // 4
    Saturday,   // 5
    Sunday      // 6
}
CSHARP
DayOfWeek today = DayOfWeek.Wednesday;   // ✅ 只能选这7个值
// DayOfWeek today = 8;                  // ❌ 编译报错！
  • 枚举 = 列出一组命名的可选值，变量只能从中选一个

枚举的底层是整数

枚举本质是整数，每个名字对应一个数字：

CSHARP
enum GameState { Menu, Playing, Paused, GameOver }
//              0     1        2        3
CSHARP
GameState state = GameState.Playing;

// 枚举 → int（强制转换）
int n = (int)state;
Console.WriteLine(n);           // 1

// int → 枚举（强制转换）
state = (GameState)2;
Console.WriteLine(state);       // Paused
💬 枚举和 int 之间用强制转换互转：
- 枚举 → int：(int)GameState.Playing → 得到 1
- int → 枚举：(GameState)2 → 得到 Paused
- 注意：int 转枚举时数字超出范围不会报错，只是一个无名称的数值——所以尽量从已有枚举值转，别拿未知数字硬转

可以自定义数值：

CSHARP
enum HttpStatus
{
    OK = 200,
    NotFound = 404,
    ServerError = 500
}

课堂练习2 — 枚举应用

用枚举管理游戏状态，结合 switch 做状态切换。

代码示例（老师示范讲解）

CSHARP
enum GameState { Menu, Playing, Paused, GameOver }
//              0     1        2        3

Console.WriteLine("当前游戏状态：");
Console.WriteLine("0-菜单 1-游戏中 2-暂停 3-结束");
Console.Write("选择状态：");
int choice = int.Parse(Console.ReadLine());

GameState state = (GameState)choice;
switch (state)
{
    case GameState.Menu:   Console.WriteLine("→ 停在主菜单"); break;
    case GameState.Playing: Console.WriteLine("→ 游戏中..."); break;
    case GameState.Paused: Console.WriteLine("→ 游戏暂停"); break;
    case GameState.GameOver: Console.WriteLine("→ 游戏结束"); break;
    default: Console.WriteLine("→ 无效状态"); break;
}
  • 动手：输入 0/1/2/3 分别观察效果，再输入 5 看 default 分支
💬 解释说明
  • (GameState)choice 把 int 转成枚举——前面学的强制转换
  • switch 配合枚举：编译器会检查是否漏了某个枚举值，不容易出错
  • 枚举让代码从 if (state == 0) 变成 state == GameState.Menu，可读性飞升

本节知识梳理

今天我们一起啃下了这些核心内容：

  • struct 结构体 — 轻量级的"小类"：适合坐标、金额这种小数据组合
  • 结构体 vs 类：struct 是值类型（复制整体），class 是引用类型
  • 结构体完整示例：定义字段+构造+方法，用法类似类
  • enum 枚举 — 给常量取个名字：enum 颜色 {红,绿,蓝} 让代码更易读

综合练习 — 纸牌花色

用枚举定义纸牌花色，用 struct 定义纸牌——枚举和结构体配合使用。

期望输入：

红心 A、黑桃 Q
（复制纸牌后修改花色为梅花，原牌应不受影响）

期望输出：

Hearts A
Spades Q
Hearts A（原牌不变——struct 值类型行为）
  • 枚举 Suit 定义四种花色，Card 结构体组合花色+点数
  • 点数 1/11/12/13 要转换成 A/J/Q/K——用 switch 表达式最简洁
  • struct 赋值是复印，改 c3 不动 c1
  • ___ 是需要你补全的地方

练习

请在下面的模板中补全空白（___）：

CSHARP
___ Suit { Spades, Hearts, Clubs, Diamonds }

___ Card
{
    public Suit Suit;
    ___ int Number;          // 1~13

    public Card(Suit s, int n)
    {
        Suit = ___;
        Number = ___;
    }

    public string GetName()
    {
        string name = Number ___
        {
            1 => "A", 11 => "J", 12 => "___", 13 => "___",
            ___ => Number.ToString()
        };
        return $"{Suit} {name}";
    }
}

// 使用
Card c1 = new Card(Suit.___, 1);     // 红心 A
Card c2 = new Card(Suit.Spades, 12); // 黑桃 Q
Console.WriteLine(c1.GetName());
Console.WriteLine(c2.GetName());

Card c3 = c1;      // 复印
c3.Suit = Suit.___;
Console.WriteLine(c1.GetName());     // 仍是红心 A
CSHARP
enum Suit { Spades, Hearts, Clubs, Diamonds }

struct Card
{
    public Suit Suit;
    public int Number;

    public Card(Suit s, int n)
    {
        Suit = s; Number = n;
    }

    public string GetName()
    {
        string name = Number switch
        {
            1 => "A", 11 => "J", 12 => "Q", 13 => "K",
            _ => Number.ToString()
        };
        return $"{Suit} {name}";
    }
}

Card c1 = new Card(Suit.Hearts, 1);
Card c2 = new Card(Suit.Spades, 12);
Console.WriteLine(c1.GetName());   // Hearts A
Console.WriteLine(c2.GetName());   // Spades Q

Card c3 = c1;
c3.Suit = Suit.Clubs;
Console.WriteLine(c1.GetName());   // Hearts A（不变）

拔高题（选做，自己写，不填空）

需求：定义枚举 Light { Red, Green, Yellow } 表示交通灯。用户输入当前灯（0/1/2），程序输出下一个灯（Red→Green→Yellow→Red 循环）。
要求：自己用枚举 + 取模运算实现切换，不能用现成模板。
CSHARP
enum Light { Red, Green, Yellow }
Light cur = (Light)int.Parse(Console.ReadLine());
Light next = (Light)(((int)cur + 1) % 3);
Console.WriteLine($"下一个灯：{next}");
