期末大作业 — 综合管理系统设计与实现

本次期末大作业是本课程的综合实践环节，要求同学们独立完成一个基于 C# + Avalonia 的桌面管理系统，综合运用类与对象、集合、文件操作与窗体编程等知识，培养从需求分析到部署演示的完整开发能力。
授课教师彭堉斌
学校汕头职业技术学院

作业目标

  • 综合运用本学期所学的 C# 语法、面向对象（类/属性/方法）、集合（List&lt;T&gt;）、文件操作 四大基础
  • 掌握 Avalonia 跨平台窗体 的程序结构：XAML 描述界面 + code-behind 写事件
  • 体验一次完整的小型软件项目：需求 → 类设计 → 界面 → 逻辑 → 持久化 → 测试 → 文档 → 答辩
  • 训练独立调试、查资料（含 AI 助教）与表达讲解的能力

题目说明 — 自选主题管理系统

本次大作业不指定单一题目，而是让你从下面的方向中任选一个（或自提一个相近主题），做一个"能增删改查、能保存数据"的桌面管理系统。

核心共同点（无论选哪个主题，都必须满足）：

  • 管理一类事物的多条记录（如多本书、多个作品、多名成员…）
  • 对这些记录能 新增、查看、修改、删除（即 CRUD 四大操作）
  • 数据要保存到文件，关闭程序再打开还在
  • 用 Avalonia 窗体 做交互界面，不是控制台

可选主题方向（灵感参考）

方向管理对象典型字段举例
个人媒体作品集作品名称、类型、完成日期、简介
图书 / 资料管理书籍书名、作者、ISBN、是否借出
宿舍信息管理寝室 / 成员楼栋、房号、姓名、电话
社团活动管理活动 / 成员活动名、时间、地点、负责人
个人记账本收支记录日期、类别、金额、备注
课程表管理课程星期、节次、课程名、教室
💡 也可以自提主题（如"宠物信息管理""游戏收藏管理"），只要满足页面3 的核心共同点即可；提前和教师确认一下更稳妥。

功能要求（必须完成）

一份合格的作业至少包含以下功能：

  • 新增记录：填写信息后点按钮，把一条记录加进列表
  • 查看 / 列表：用 ListBox 或 DataGrid 显示所有记录
  • 修改记录：选中一条 → 编辑 → 保存
  • 删除记录：选中一条 → 删除（建议加确认提示，用 TextBlock 显示）
  • 查询 / 筛选：按关键字或条件下拉筛选（至少一种）
  • 保存与加载：退出前自动/手动保存到文件；启动时自动加载
  • 输入校验：空值、格式错误要有友好提示（用 TextBlock，不用 MessageBox）
⚠️ 没有"保存到文件"功能的，最多只能拿功能分的一半——持久化是硬指标。

技术要求（评分硬指标）

技术要求说明
至少一个自定义类（Model）含属性（get/set）、构造方法、必要业务方法
用 List<T> 集合存储不直接用数组硬凑
文件读写持久化System.IO 读写 txt/csv，重启不丢数据
Avalonia 窗体界面MainWindow.axaml + code-behind
至少 4 种控件如 TextBox / Button / ListBox / ComboBox / CheckBox 等
事件驱动按钮 Click 等事件关联 C# 方法（RoutedEventArgs）
输入校验防止空输入 / 格式错误导致崩溃（TryParse 等）
💡 提示：课件18「图书管理系统」就是标准范本——一个 Book 类 + List<Book> + 文件读写 + 界面事件。照着改主题就行。

项目结构参考（三层）

  • 界面层：MainWindow.axaml 负责长相，MainWindow.axaml.cs 负责按钮事件
  • 模型层：一个 XxxItem 类描述"一条记录"长什么样
  • 数据层：负责把集合存成文件、从文件读回集合
  • 三者通过"事件方法"串起来：点按钮 → 改集合 → 刷新界面 → 存文件

参考案例框架 — 以"图书管理"为例

下面是一套可直接套用的骨架，把 Book 换成你的主题类即可。
CSHARP
// 1) 模型类：一条记录
public class Book
{
    public int Id { get; set; }
    public string Title { get; set; } = "";
    public string Author { get; set; } = "";
    public bool IsBorrowed { get; set; }
}

// 2) 数据集合 + 文件读写（放在 MainWindow.axaml.cs 或单独类）
List<Book> books = new();
string file = "books.txt";

void Load()
{
    books.Clear();
    if (File.Exists(file))
        foreach (var line in File.ReadAllLines(file))
        {
            var p = line.Split('|');
            books.Add(new Book
            {
                Id = int.Parse(p[0]),
                Title = p[1],
                Author = p[2],
                IsBorrowed = bool.Parse(p[3])
            });
        }
}

void Save()
{
    var lines = books.Select(b => $"{b.Id}|{b.Title}|{b.Author}|{b.IsBorrowed}");
    File.WriteAllLines(file, lines);
}
XML
<!-- 3) 界面骨架：MainWindow.axaml -->
<StackPanel Margin="20" Spacing="10">
    <TextBox x:Name="titleBox" Watermark="书名" />
    <TextBox x:Name="authorBox" Watermark="作者" />
    <Button x:Name="addBtn" Content="新增" Click="AddBtn_Click" />
    <ListBox x:Name="listBox" />
    <TextBlock x:Name="hint" />
</StackPanel>
  • 绑定列表：简单场景用 listBox.Items.Add(...) 即可；数据多变也可用 listBox.ItemsSource = books
  • 提示信息一律用 hint.Text = "..."，Avalonia 没有 MessageBox

开发步骤与时间安排

建议按下面的节奏推进（共 2~3 周）：

  1. 第1天：定主题 + 列字段 — 确定管理什么、每条记录有哪些字段
  2. 第2~3天：写模型类 + 集合 — 先把 XxxItem 类和 List<XxxItem> 跑通
  3. 第4~6天：搭界面 + 事件 — XAML 摆控件，code-behind 写增删改查
  4. 第7~8天：文件持久化 — 加 Load/Save，确保重启不丢
  5. 第9~10天：校验 + 美化 — 输入校验、布局整理、提示友好
  6. 答辩前：写文档 + 演练 — 类图、功能说明、使用说明、截图
💡 卡住先用 AI 助教（课件2 四步法），但最终代码必须自己写、自己讲得清。

温馨提示与常见坑

  • ❌ 别等到最后两天才写——GUI + 文件 + 调试至少需要一周
  • ❌ 别用 MessageBox.Show——Avalonia 没有，改用 TextBlock 提示
  • ❌ 别把数据只放内存——没写文件，关掉就没了，持久化分直接丢
  • ✅ 多用 TryParse / 空值判断，避免输入非法直接崩溃
  • ✅ 每加一个功能就运行试一次，别攒到最后一起调
  • ✅ 答辩重点讲"你的类怎么设计、事件怎么串起来"，比炫界面更得分
