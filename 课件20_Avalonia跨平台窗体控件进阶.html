CheckBox — 多选框

XML
<CheckBox x:Name="chkMusic" Content="音乐" />
<CheckBox x:Name="chkSport" Content="运动" />
<CheckBox x:Name="chkGame" Content="游戏" />
<Button x:Name="okBtn" Content="确定" Click="OkBtn_Click" />
<TextBlock x:Name="result" />
CSHARP
// 每个 CheckBox 独立，互不影响
// CheckBox 的核心属性：IsChecked 是 bool?（null=未定，本课只用 true/false）
public void OkBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    string hobbies = "你的爱好：";
    if (chkMusic.IsChecked == true) hobbies += "音乐 ";
    if (chkSport.IsChecked == true) hobbies += "运动 ";
    if (chkGame.IsChecked == true)  hobbies += "游戏 ";

    if (chkMusic.IsChecked != true && chkSport.IsChecked != true && chkGame.IsChecked != true)
        hobbies = "你啥爱好都没有？";

    result.Text = hobbies;
}
属性说明
IsCheckedtrue=选中，false=未选（类型是 bool?）
Content选框后面的文字

RadioButton — 单选按钮

RadioButton 一组中只能选一个。关键：用 GroupName 属性分组——同 GroupName 的自动互斥，不同 GroupName 互不影响（不再需要 GroupBox 容器）。

XML
<RadioButton x:Name="rdoMale" GroupName="gender" Content="男" />
<RadioButton x:Name="rdoFemale" GroupName="gender" Content="女" />
<RadioButton x:Name="rdoU18" GroupName="age" Content="18岁以下" />
<RadioButton x:Name="rdo18to30" GroupName="age" Content="18-30岁" />
<RadioButton x:Name="rdoO30" GroupName="age" Content="30岁以上" />
CSHARP
public void OkBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    string gender = rdoMale.IsChecked == true ? "男" : "女";

    string age = "";
    if (rdoU18.IsChecked == true) age = "18岁以下";
    else if (rdo18to30.IsChecked == true) age = "18-30岁";
    else if (rdoO30.IsChecked == true) age = "30岁以上";

    result.Text = $"性别：{gender}，年龄段：{age}";
}
属性说明
IsChecked是否被选中（bool?）
Content选项文字
GroupName分组名，同组互斥

ComboBox — 下拉选择框

XML
<ComboBox x:Name="gradeBox">
    <ComboBoxItem Content="大一" />
    <ComboBoxItem Content="大二" />
    <ComboBoxItem Content="大三" />
</ComboBox>
<Button x:Name="okBtn" Content="确定" Click="OkBtn_Click" />
<TextBlock x:Name="result" />
CSHARP
public void OkBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    // SelectedItem 是 ComboBoxItem，取它的 Content 才是文字
    if (gradeBox.SelectedItem is ComboBoxItem item)
        result.Text = $"你选择了：{item.Content}";
    else
        result.Text = "⚠️ 请先选择一个选项";   // 没有 MessageBox，用 TextBlock 提示
}
属性说明
Items / 子元素选项集合，XAML 里直接写 <ComboBoxItem>
SelectedItem选中的项（是 ComboBoxItem 对象）

ListBox — 列表框

XML
<ListBox x:Name="listMenu" SelectionMode="Multiple">
    <ListBoxItem Content="汉堡" />
    <ListBoxItem Content="薯条" />
    <ListBoxItem Content="可乐" />
</ListBox>
<Button x:Name="showBtn" Content="显示选中" Click="ShowBtn_Click" />
<TextBlock x:Name="result" />
CSHARP
public void ShowBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    // 遍历所有选中的项
    string text = "选中：";
    foreach (var item in listMenu.SelectedItems)
        if (item is ListBoxItem lbi) text += lbi.Content + " ";
    result.Text = text;
}
属性说明
Items / 子元素列表项，XAML 里直接写 <ListBoxItem>
SelectedItems选中的多个项（多选时用）
SelectionModeSingle = 单选，Multiple = 多选
  • 添加项也可在代码里：listMenu.Items.Add("鸡翅");
  • 删除选中项：listMenu.Items.Remove(listMenu.SelectedItem);

其他常用控件

NumericUpDown — 数字输入框：

限制用户只能输入数字，有 ▲▼ 按钮调节。关键属性：

XML
<NumericUpDown x:Name="scoreBox" Minimum="0" Maximum="100" Value="5" />
CSHARP
// 读取值：Value 是 decimal 类型，给 int 用需强转 (int)
int qty = (int)scoreBox.Value;
double price = 9.9;
result.Text = $"总价：{qty * price:F1}";

// 常用属性（在 XAML 里设置）：
// Minimum = 0, Maximum = 100   → 限制范围
// DecimalPlaces = 0           → 小数位数（0=整数）
// Increment = 1               → 每次点击增减多少
// Value = 5                   → 默认值

分组（替代 GroupBox）：

Avalonia 没有 GroupBox 容器。用 布局容器 + 一个 TextBlock 标题 来分组即可，例如用 StackPanel 包一组控件，上面放标题文字：

XML
<StackPanel>
    <TextBlock Text="性别" FontWeight="Bold" />
    <RadioButton GroupName="gender" Content="男" />
    <RadioButton GroupName="gender" Content="女" />
</StackPanel>

Image — 图片显示（替代 PictureBox）：

XML
<Image x:Name="photo" Source="photo.jpg" />
CSHARP
// 代码动态换图（图片放到项目根目录，并设为"复制到输出目录"）：
using Avalonia.Media.Imaging;
photo.Source = new Bitmap("photo.jpg");
  • 注意：Avalonia 没有 PictureBox 和 Image.FromFile，图片控件叫 Image，用 Source 设图片（Bitmap）

Slider — 滑块：

拖动选一个范围内的值，比 NumericUpDown 更直观：

XML
<Slider x:Name="volSlider" Minimum="0" Maximum="100" Value="50" />
CSHARP
int v = (int)volSlider.Value;   // 拖动后读取当前值

Border — 边框 / 底色（给一组控件加框分组）：

XML
<Border BorderBrush="Gray" BorderThickness="1" CornerRadius="6" Padding="10">
    <StackPanel>
        <TextBlock Text="一组内容" />
    </StackPanel>
</Border>

ScrollViewer — 滚动区域：内容超出容器高度时自动出现滚动条：

XML
<ScrollViewer Height="200">
    <StackPanel> ...很多控件... </StackPanel>
</ScrollViewer>

ToolTip — 悬浮提示：鼠标移到控件上显示说明文字：

XML
<Button Content="?" ToolTip.Tip="点这里保存" />
💡 控件地图小结：本课已学——文本(TextBlock/TextBox)、按钮(Button)、选择(CheckBox/RadioButton/ComboBox/ListBox)、数字(NumericUpDown/Slider)、图片(Image)、布局(StackPanel/Grid/DockPanel/WrapPanel/Canvas)。Avalonia 控件很多，记住"画窗口、摆控件、写事件"这套路，遇到新控件查官方文档即可。

课堂练习1 — 学生信息登记表

用 RadioButton（单选）、CheckBox（多选）、ComboBox（下拉）、NumericUpDown（数字）收集信息，提交后汇总显示——综合运用多种输入控件。

代码示例（老师示范讲解）

XML
<StackPanel Margin="20" Spacing="10">
    <TextBox x:Name="nameBox" Watermark="姓名" />
    <StackPanel>
        <TextBlock Text="性别" FontWeight="Bold" />
        <RadioButton x:Name="rdoMale" GroupName="g" Content="男" />
        <RadioButton x:Name="rdoFemale" GroupName="g" Content="女" />
    </StackPanel>
    <StackPanel>
        <TextBlock Text="爱好" FontWeight="Bold" />
        <CheckBox x:Name="chkMusic" Content="音乐" />
        <CheckBox x:Name="chkSport" Content="运动" />
        <CheckBox x:Name="chkGame" Content="游戏" />
    </StackPanel>
    <ComboBox x:Name="gradeBox">
        <ComboBoxItem Content="大一" />
        <ComboBoxItem Content="大二" />
        <ComboBoxItem Content="大三" />
    </ComboBox>
    <NumericUpDown x:Name="scoreBox" Minimum="0" Maximum="100" Value="5" />
    <Button x:Name="submitBtn" Content="提交" Click="SubmitBtn_Click" />
    <TextBlock x:Name="result" />
</StackPanel>
CSHARP
public void SubmitBtn_Click(object? sender, Avalonia.Interactivity.RoutedEventArgs e)
{
    string name = nameBox.Text;
    string gender = rdoMale.IsChecked == true ? "男" : "女";

    string hobbies = "";
    if (chkMusic.IsChecked == true) hobbies += "音乐 ";
    if (chkSport.IsChecked == true) hobbies += "运动 ";
    if (chkGame.IsChecked == true)  hobbies += "游戏 ";
    if (string.IsNullOrEmpty(hobbies)) hobbies = "无";

    string grade = gradeBox.SelectedItem is ComboBoxItem gi ? gi.Content.ToString() : "未选";
    int score = (int)scoreBox.Value;

    result.Text = $"姓名：{name}
性别：{gender}
爱好：{hobbies}
年级：{grade}
评分：{score}";
}
  • 动手：把 NumericUpDown 的 Maximum 从 100 改成 30，再改回 100，对比控件变化
💬 解释说明
  • RadioButton 要互斥，必须设相同的 GroupName（如 GroupName="g"），否则可以同时选中
  • CheckBox.IsChecked 是 bool?（可空布尔），用 == true 判断最安全
  • ComboBoxItem 的 Content 才是文字，SelectedItem 是选中的整行对象，要 as ComboBoxItem 转换后再取 .Content
  • NumericUpDown 直接 .Value 取数字，设 Minimum/Maximum 限制范围

本节知识梳理

今天我们一起啃下了这些核心内容：

  • CheckBox — 多选框：可同时勾多个，IsChecked 看是否选中
  • RadioButton — 单选按钮：同 GroupName 里只能选一个
  • ComboBox — 下拉选择框：点开选一项，省空间
  • ListBox — 列表框：列出多项可单选/多选
  • 其他常用控件：Image 显示图片、ProgressBar 进度条等
💡 接下来是「综合练习」——不再是单个知识点的小练习，而是把上面这些串起来解决一个真实小任务。先自己动手写，实在卡住再看答案。

综合练习 — 简单点餐系统

从菜单 ListBox 选菜品 → 点"添加"加入已选 ListBox → 自动计算总价——综合运用 ListBox、Dictionary、事件处理。

期望输入：

菜单列表：汉堡(¥15) / 薯条(¥10) / 可乐(¥8) / 鸡翅(¥12)
操作：选"汉堡"→ 点"添加"→ 选"可乐"→ 点"添加"
（点"汉堡"再点"<<移除"→ 汉堡从已选消失，总价减少15）

期望输出：

已选列表：汉堡、可乐
总计：¥23
  • 菜品和价格用 Dictionary<string,int> 存储，menu["汉堡"] 直接取值
  • ListBox 的选中项通过 SelectedItem is ListBoxItem 判断类型后取 .Content
  • 总价用 int total 字段累加；移除时 total -= menu[...] 减去
  • ___ 是需要你补全的地方
