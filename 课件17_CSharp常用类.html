Math — 数学计算

当你要算圆的面积时——Math.PI * Math.Pow(半径, 2)，一行搞定。C# 把数学公式全封装在 Math 类里，拿来就用。
方法作用示例
Math.Abs(x)绝对值Abs(-5) → 5
Math.Max(a,b) / Min(a,b)最大值/最小值Max(10,20) → 20
Math.Pow(x,y)x 的 y 次方Pow(2,3) → 8
Math.Sqrt(x)平方根Sqrt(16) → 4
Math.Round(x,n)四舍五入到 n 位Round(3.14159,2) → 3.14
Math.Floor(x) / Ceiling(x)向下/向上取整Floor(3.9) → 3
Math.PI圆周率常量3.14159...
CSHARP
namespace HelloWorld
{
using System;

    class Program
    {
        static void Main()
        {
            // 绝对值、最大值、最小值
            Console.WriteLine(Math.Abs(-5));            // 5
            Console.WriteLine(Math.Max(10, 20));        // 20
            Console.WriteLine(Math.Min(10, 20));        // 10

            // 幂和开方
            Console.WriteLine(Math.Pow(2, 3));          // 8（2的3次方）
            Console.WriteLine(Math.Sqrt(16));           // 4（平方根）

            // 四舍五入
            Console.WriteLine(Math.Round(3.5));         // 4
            Console.WriteLine(Math.Round(3.14159, 2));  // 3.14（保留2位）

            // 取整
            Console.WriteLine(Math.Floor(3.9));         // 3（向下取整）
            Console.WriteLine(Math.Ceiling(3.1));       // 4（向上取整）

            // 常量
            Console.WriteLine(Math.PI);                 // 3.14159265358979...
        }
    }
}

DateTime — 日期时间

当你要算自己活了多少天时——DateTime.Today - 生日，直接拿到天数。日期加减、格式化输出都在 DateTime 里。
方法/属性作用示例
DateTime.Now当前日期时间2026-07-01 14:30:00
DateTime.Today今天（时间归零）2026-07-01 00:00:00
new DateTime(y,m,d)指定日期new DateTime(2000,1,1)
dt.AddDays(n) / AddMonths(n)加减天/月today.AddDays(7) → 下周
dt2 - dt1日期差 → TimeSpannow - birthday → 活了 X 天
dt.ToString("格式")格式化输出"yyyy-MM-dd"
CSHARP
namespace HelloWorld
{
using System;

    class Program
    {
        static void Main()
        {
            DateTime now = DateTime.Now;          // 当前日期时间
            DateTime today = DateTime.Today;      // 今天（时间部分为 00:00）

            // 创建指定日期
            DateTime birthday = new DateTime(2000, 1, 1);

            // 日期计算
            DateTime tomorrow = today.AddDays(1);       // 明天
            DateTime nextWeek = today.AddDays(7);       // 下星期
            DateTime nextMonth = today.AddMonths(1);    // 下个月

            // 求日期差
            TimeSpan age = now - birthday;
            Console.WriteLine($"出生 {age.Days} 天");

            // 格式化输出
            Console.WriteLine(now.ToString("yyyy-MM-dd"));       // 2026-07-01
            Console.WriteLine(now.ToString("yyyy年MM月dd日"));    // 2026年07月01日
        }
    }
}

Random — 随机数

当你要写个抽奖程序时——new Random().Next(0, 名单长度)，随机选一个人。骰子、硬币、验证码，全靠 Random。
方法作用示例
new Random()创建随机数生成器Random rand = new Random();
rand.Next()任意非负整数Next() → 0~21亿
rand.Next(max)0 ~ max-1Next(100) → 0~99
rand.Next(min,max)min ~ max-1Next(1,7) → 1~6
rand.NextDouble()0.0 ~ 1.0 小数NextDouble() → 0.73...
CSHARP
namespace HelloWorld
{
using System;

    class Program
    {
        static void Main()
        {
            Random rand = new Random();

            int n1 = rand.Next();          // 任意非负随机整数
            int n2 = rand.Next(100);       // 0 ~ 99
            int n3 = rand.Next(1, 7);      // 1 ~ 6（骰子）

            double d = rand.NextDouble();  // 0.0 ~ 1.0 之间的小数

            Console.WriteLine($"Next(): {n1}, Next(100): {n2}, 骰子: {n3}, NextDouble: {d:F4}");

            // 生成 1~100 的随机数
            int answer = rand.Next(1, 101);
            Console.WriteLine($"1~100 随机数：{answer}");

            // 随机从数组中选一个
            string[] names = { "张三", "李四", "王五" };
            string lucky = names[rand.Next(names.Length)];
            Console.WriteLine($"幸运儿：{lucky}");

            // 随机布尔值
            bool coin = rand.Next(2) == 1;    // true/false 各 50%
            Console.WriteLine($"硬币：{(coin ? "正面" : "反面")}");
        }
    }
}

Convert — 类型转换

用户输入永远是 string——"25" 想拿来算，得先变成 int。Convert 就是专门做这个的，而且比 Parse 更宽容。
方法作用入参为 null
Convert.ToInt32(s)string → int返回 0 ✅
Convert.ToDouble(s)string → double返回 0 ✅
Convert.ToBoolean(s)string → bool返回 false ✅
Convert.ToString(x)任意类型 → string""
int.Parse(s)对比：同功能💥 抛异常
CSHARP
namespace HelloWorld
{
using System;

    class Program
    {
        static void Main()
        {
            // string → 数值
            int age = Convert.ToInt32("25");
            double pi = Convert.ToDouble("3.14");
            bool flag = Convert.ToBoolean("true");

            Console.WriteLine($"age={age}, pi={pi}, flag={flag}");

            // 数值 → string
            string s = Convert.ToString(12345);
            Console.WriteLine(s);

            // vs int.Parse() 的区别
            Console.WriteLine(Convert.ToInt32(null));   // ✅ 返回 0（更宽容）
            // int.Parse(null);                         // 💥 抛异常
        }
    }
}

Path — 文件路径处理

C:\照片\2026\me.jpg 这个路径，怎么取出文件名、后缀名、目录？Path 类专门干这个，再也不用自己拆字符串了。
方法作用示例（path = C:\照片\me.jpg）
Path.GetFileName(p)取文件名"me.jpg"
Path.GetFileNameWithoutExtension(p)无后缀文件名"me"
Path.GetExtension(p)取后缀".jpg"
Path.GetDirectoryName(p)取目录"C:\照片"
Path.Combine(a,b,c)安全拼接路径"C:\照片\2026"
CSHARP
namespace HelloWorld
{
using System;
using System.IO;

    class Program
    {
        static void Main()
        {
            string path = @"C:\Users\张三\Documents\report.docx";

            Console.WriteLine(Path.GetFileName(path));           // "report.docx"
            Console.WriteLine(Path.GetFileNameWithoutExtension(path));  // "report"
            Console.WriteLine(Path.GetExtension(path));          // ".docx"
            Console.WriteLine(Path.GetDirectoryName(path));      // "C:\Users\张三\Documents"
            Console.WriteLine(Path.Combine("C:", "Users", "张三"));  // "C:\Users\张三"

            // 检查路径相关
            Console.WriteLine(File.Exists(path));                // 文件是否存在
            Console.WriteLine(Directory.Exists(@"C:\Users"));    // 目录是否存在
        }
    }
}

课堂练习1 — 速算挑战

程序随机出5道两位数加法题，用户输入答案，计时评分——一次练 Random、Convert、Math 和 DateTime。

期望运行效果：

代码示例（老师示范讲解）

第1题：34 + 57 = 91
✅ 正确！
第2题：12 + 88 = 100
✅ 正确！
...
做对 4/5 题，用时 23.5 秒
CSHARP
namespace HelloWorld
{
using System;

    class Program
    {
        static void Main()
        {
            Random rand = new Random();
            DateTime start = DateTime.Now;  // 计时开始
            int score = 0;

            for (int i = 1; i <= 5; i++)
            {
                int a = rand.Next(10, 100);  // Random：10~99 的随机数
                int b = rand.Next(10, 100);
                Console.Write($"第{i}题：{a} + {b} = ");
                int answer = Convert.ToInt32(Console.ReadLine());  // Convert：用户输入转 int

                if (Math.Abs(answer - (a + b)) == 0)  // Math.Abs：判断差值是否为0
                {
                    Console.WriteLine("✅ 正确！");
                    score++;
                }
                else
                {
                    Console.WriteLine($"❌ 错了，答案是 {a + b}");
                }
            }

            double seconds = (DateTime.Now - start).TotalSeconds;  // DateTime：计算用时
            Console.WriteLine($"做对 {score}/5 题，用时 {Math.Round(seconds, 1)} 秒");
        }
    }
}
  • 动手：把5题改成10题；把加法改成乘法（*），体验四类知识联动
💬 解释说明
  • rand.Next(10, 100) — Random 生成题目数字（页面5）
  • Convert.ToInt32(Console.ReadLine()) — Convert 把用户输入转 int（页面6）
  • Math.Abs(answer - (a + b)) == 0 — Math 判断答对没有（页面3）
  • (DateTime.Now - start).TotalSeconds — DateTime 计时（页面4）
  • 四行代码，四个类联动——这就是"常用类"的真实用法

namespace HelloWorld
{
using System;
using System.IO;

    class Program
    {
        static void Main()
        {
            string[] lines = File.ReadAllLines("scores.txt");

            int totalScore = 0, studentCount = 0;
            string topStudent = "";
            int topScore = 0;

            Console.WriteLine("====================");
            Console.WriteLine($"成绩分析报告  {DateTime.Now:yyyy-MM-dd}");
            Console.WriteLine("====================");

            foreach (string line in lines)
            {
                string[] parts = line.Split(' ');
                string name = parts[0];
                int s1 = Convert.ToInt32(parts[1]);
                int s2 = Convert.ToInt32(parts[2]);
                int s3 = Convert.ToInt32(parts[3]);

                int sum = s1 + s2 + s3;
                double avg = Math.Round((double)sum / 3, 1);

                Console.WriteLine($"{name}: 总分{sum} 平均{avg}");
                totalScore += sum;
                studentCount++;

                if (sum > topScore)
                {
                    topScore = sum;
                    topStudent = name;
                }
            }

            double classAvg = Math.Round((double)totalScore / studentCount, 1);
            Console.WriteLine("--------------------");
            Console.WriteLine($"全班平均分：{classAvg}");
            Console.WriteLine($"最高分学生：{topStudent}（{topScore}分）");
        }
    }
}

拔高题（选做，自己写，不填空）

需求：让用户输入一个目标日期（如 2026-12-31），程序算出距离今天还有多少天。

CSHARP
using System;

namespace HelloWorld
{
    class Program
    {
        static void Main()
        {
