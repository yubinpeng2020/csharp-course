程序执行的三种结构

所有程序，无论多复杂，都由这三种基本结构组合而成。

🔵 顺序结构 — 一行接一行

语句1 → 语句2 → 语句3 → ...
  • 从上往下逐行执行，最基础、最简单的结构
  • 📖 就像看书翻页，一页读完翻下一页

🟠 分支结构 — 看情况选择

条件？ ─┬─ true → 走 A 路
        └─ false → 走 B 路
  • 根据条件决定执行哪段代码
  • 🚦 就像岔路口，红灯停、绿灯行

🟢 循环结构 — 重复做一件事

满足条件？→ 是 → 执行 → 再检查 → …
              ↘ 不满足 → 结束
  • 让一段代码反复执行
  • 🏃 就像操场跑圈，跑满了才停
🎯 本课件讲分支，循环后面课件会讲到。

单分支 if

CSHARP
if (条件)
{
    // 条件为 true 时执行
}
CSHARP
int score = 85;
if (score >= 60)
{
    Console.WriteLine("你及格了！");
}
// score=85 → 输出"你及格了！"
// score=50 → 什么都不输出
  • 条件必须是 bool 类型（true/false）
  • 只有条件成立时，{ } 里的代码才执行

快速回顾 — 关系运算符

if 的条件通常用关系运算符构成：

运算符含义示例
>大于a > 10
<小于a < 0
>=大于等于score >= 60
<=小于等于age <= 18
==等于level == 3
!=不等于name != ""
  • ⚠️ == 是比较，= 是赋值，别搞混
CSHARP
  if (a = 10)   // ❌ 编译错误！= 是赋值，int 不能当 bool
  if (a == 10)  // ✅ 正确
  • ⚠️ 更隐蔽的坑——bool 变量不会报错，但逻辑全乱
CSHARP
  bool doorOpen = false;
  if (doorOpen = true)  // ❌ = 是赋值！doorOpen 被改成 true，if 永远进
  if (doorOpen == true) // ✅ == 是比较

逻辑运算符组合条件

运算符含义示例
&&与（都要满足）age >= 18 && age <= 60
||或（满足一个）score < 0 || score > 100
!非（取反）!isPass
CSHARP
int age = 25;
if (age >= 18 && age <= 60)
{
    Console.WriteLine("你是劳动力人口");
}

int score = 120;
if (score < 0 || score > 100)
{
    Console.WriteLine("分数无效！");
}
💡 回顾课件4：&& 左边为 false 时不执行右边，|| 左边为 true 时不执行右边（短路特性）

双分支 if-else

CSHARP
if (条件)
{
    // 条件为 true 时执行
}
else
{
    // 条件为 false 时执行
}
CSHARP
int score = 55;
if (score >= 60)
{
    Console.WriteLine("及格");
}
else
{
    Console.WriteLine("不及格");
}
// 输出：不及格
  • 两条路必走一条，不会都不执行

多分支 if-else if

CSHARP
if (条件1)
{
    // 条件1成立
}
else if (条件2)
{
    // 条件1不成立，条件2成立
}
else if (条件3)
{
    // 条件1、2不成立，条件3成立
}
else
{
    // 以上都不成立
}
  • 从上往下逐个判断，第一个成立的就执行，后面的不再判断

示例：成绩等级判断

CSHARP
Console.Write("请输入成绩：");
int score = int.Parse(Console.ReadLine());

if (score >= 90)
{
    Console.WriteLine("等级：A");
}
else if (score >= 80)
{
    Console.WriteLine("等级：B");
}
else if (score >= 70)
{
    Console.WriteLine("等级：C");
}
else if (score >= 60)
{
    Console.WriteLine("等级：D");
}
else
{
    Console.WriteLine("等级：F（不及格）");
}
  • ⚠️ 注意顺序：>= 90 必须放最前面。如果先写 >= 60，90分也会被判为 D

嵌套 if

CSHARP
if (isMember)           // 外层：是会员？
{
    if (amount >= 500)  // 内层：消费满500？
    {
        Console.WriteLine("打8折！");
    }
    else
    {
        Console.WriteLine("打9折！");
    }
}
else
{
    Console.WriteLine("原价，或先注册会员");
}
  • 嵌套不要超过3层，否则逻辑很难追踪
  • 书写时缩进，让层次清晰

switch 语句

当一个变量有多个固定取值，每个值对应一种操作，用 switch 比 if-else if 更清晰。
CSHARP
switch (表达式)
{
    case 值1:
        // 匹配值1时执行
        break;
    case 值2:
        // 匹配值2时执行
        break;
    default:
        // 都不匹配时执行
        break;
}
  • break; 不能忘——用来跳出 switch，阻止继续往下执行
  • 不加 break;，C# 会直接编译报错（不像 C/C++ 那样会"穿透"到下一个 case）

示例：输入数字，输出星期

CSHARP
Console.Write("输入数字1-7：");
int day = int.Parse(Console.ReadLine());
string dayName;

switch (day)
{
    case 1: dayName = "星期一"; break;
    case 2: dayName = "星期二"; break;
    case 3: dayName = "星期三"; break;
    case 4: dayName = "星期四"; break;
    case 5: dayName = "星期五"; break;
    case 6: dayName = "星期六"; break;
    case 7: dayName = "星期日"; break;
    default: dayName = "无效数字"; break;
}
Console.WriteLine(dayName);
  • 💡 switch 表达式（简写版）：当 switch 只是用来选一个值时，可以更简洁
CSHARP
  Console.Write("输入数字1-7：");
  int day = int.Parse(Console.ReadLine());
  string dayName = day switch
  {
      1 => "星期一",
      2 => "星期二",
      3 => "星期三",
      4 => "星期四",
      5 => "星期五",
      6 => "星期六",
      7 => "星期日",
      _ => "无效数字"    // _ 代表"其他所有情况"
  };
  Console.WriteLine(dayName);

和传统 switch 效果一样，但不需要 break 和重复赋值。后面课件会用到这种写法。

switch 和 if 条件的核心区别：

ifswitch
条件类型可以是 >、<、== 等任意比较只能是相等的固定值
示例if (score >= 90) ✅switch (90) ❌ 没有实际意义
if (day == 1) ✅switch (day) { case 1: ... } ✅
简而言之：if 判断"是或不是"（比较），switch 判断"是哪个"（匹配固定值）。
场景推荐理由
判断范围（>、<）if-else ifswitch 不支持范围比较
判断相等（固定值）switch代码更清晰整齐
判断条件复杂if-else ifswitch 只判断单一变量
少量分支（2-3个）if-else够用就行
CSHARP
// 判断范围 → 用 if-else if
if (score >= 90) { ... }        // ✅ if-else if
else if (score >= 80) { ... }

// 判断固定值 → 用 switch
switch (level)                   // ✅ switch
{ case 1: ... case 2: ... }

课堂练习2 — switch 练习

用 switch 实现四则运算选择器：输入运算符和两个数，输出结果。

代码示例（老师示范讲解）

CSHARP
Console.Write("请选择操作（+、-、*、/）：");
char op = char.Parse(Console.ReadLine());

Console.Write("输入数字1：");
double a = double.Parse(Console.ReadLine());
Console.Write("输入数字2：");
double b = double.Parse(Console.ReadLine());

switch (op)
{
    case '+': Console.WriteLine($"{a}+{b}={a+b}"); break;
    case '-': Console.WriteLine($"{a}-{b}={a-b}"); break;
    case '*': Console.WriteLine($"{a}*{b}={a*b}"); break;
    case '/': Console.WriteLine($"{a}/{b}={a/b}"); break;
    default: Console.WriteLine("无效操作符"); break;
}
  • 动手：把 switch 改成 if-else if，看哪种写法更清晰
💬 解释说明
  • switch 适合「一个变量匹配多个固定值」的场景
  • break 不能忘，否则会穿透到下一个 case
  • default 是都不匹配时的兜底分支

本节知识梳理

今天我们一起啃下了这些核心内容：

  • 程序执行的三种结构：顺序、分支、循环
  • 单分支 if：if(条件){...} 条件为真才执行
  • 逻辑运算符组合条件：用 &&/|| 把多个判断拼起来
  • 双分支 if-else：条件真走 if，假走 else
  • 多分支 if-else if：一档一档往下判断，命中即停
  • 嵌套 if：if 里再套 if，处理更细的条件
  • switch 语句：对一个变量的多个固定值做分支，比 if 链清晰
💡 接下来是「综合练习」——不再是单个知识点的小练习，而是把上面这些串起来解决一个真实小任务。先自己动手写，实在卡住再看答案。
