计算机实验室学生守则（一至五）

🚪 出入规范

一、学生课内上机，必须按照机房上机安排表指定机房和机器；非课内上机时间，未经允许不得擅自进入机房使用机器。

二、学生上机应衣着整洁，佩带胸卡，严禁仅穿背心、短裤、拖鞋进入机房。不得迟到、早退。除与学习内容相关的教材资料外，其它物品未经许可不准带入实验室。

三、进入实验室应在门外脱鞋，不穿鞋入室，把自带鞋放于鞋架上；离开实验室时，应在实验室门外穿鞋。保持实验室整洁美观。

💻 上机纪律

四、服从管理人员及指导老师的安排，按编定座位上机，未经同意不准调换座位。因机器故障需要调换位置者，应由指导老师或实验室管理人员安排。

五、爱护公物。使用光驱、键盘、鼠标器等设备应轻按、轻放、轻敲。上机过程中，若设备出现故障应立即报告指导老师或实验室管理人员，以便及时维修。

计算机实验室学生守则（六至十）

🛡️ 行为准则

六、按照教学内容进行操作。严格遵守机房设备操作规程。上机时不准玩游戏、上网聊天等进行与教学内容无关的操作。上机时不准观看、传播、拷贝和制作淫秽、反动、迷信等不健康内容。上机时不准编制、运行和使用危害计算机系统和其它用户安全的程序、命令；不准更改CMOS口令和用户帐号口令；不准安装与教学内容无关的软件和内容；不准私自改变系统的软硬件设置等进行破坏性操作。对违反者造成的法律和教学事故的，将追究其责任；造成设备损坏的按价赔偿并严肃处理。

🧹 环境卫生

七、保持实验室安静整洁。不得喧闹、嬉戏；不得乱丢纸屑杂物、吐痰；不得吸烟、吃零食，将水、饮料带入实验室；不得在设备、桌椅、墙壁上涂写。上机结束应关闭计算机设备电源；把桌面收拾干净，把设备椅子摆放整齐；把面巾纸草稿纸等杂物丢进字纸篓。

⚠️ 安全与处罚

八、不得自行关闭或调节监控设备、空调设备和稳压电源；不得拆卸任何设备；一切学院财产未经同意，不准擅自拿出实验室。

九、应急安全门用于紧急情况，如火灾、自然灾害等，其它时候不得开启使用。

十、违反上述规定者，视其情节轻重，给予批评教育、警告、取消上机资格，直至交学院有关部门处理。以上《守则》希望大家共同遵守。

🧠 什么是编程思维？

  • 不是记语法，是解决问题的思路
  • 把复杂问题拆成小问题，一步步执行
普通思维编程思维
🚪 把门打开🔍 找到门把手 → ✊ 握住 → 🔄 向下旋转 → 👉 推门 → ✅ 确认已打开
🍳 做番茄炒蛋🛒 买菜 → 🚿 洗菜 → 🔪 切菜 → 🥚 打蛋 → 🍳 下锅炒 → 🧂 调味 → 🍽️ 出锅
每一步都是确定的、按顺序执行的——这就是编程思维，生活里到处都是。
能。编程不是做数学题，它更像写菜谱——把步骤想清楚就能写代码。数学求「最优解」，编程求「可行解」：1+2+...+100，数学用公式秒算，编程老老实实加 100 次也能得到答案。
能。C# 关键字就几十个（int、if、for...），见多了自然认识。报错信息看不懂？用 AI 翻译，看中文解释。英语不是门槛，动手写才是。
本学期每一道题，都是在练这个拆解问题的能力。语法忘了可以查，思路不会就卡死了。

C#语言简介

编程语言发展简史

时代标志
💾 1946-1950 机器语言穿孔卡片，直接操控硬件
📝 1950-1960 汇编语言用助记符代替 0 和 1
🚀 1957-今 高级语言Fortran(1957) → C(1972) → C++(1983) → Java(1995) → C#(2000)
从穿卡片到敲键盘，C# 站在 50 年语言演进之巅。

C#（读作 C Sharp）是微软在 2000 年发布的面向对象高级编程语言。

特点一句话说明
📝 语法简洁易于学习和使用
🧱 面向对象彻底的面向对象设计
🛡️ 类型安全编译时检查类型，减少错误
♻️ 自动垃圾回收自动管理内存，不用手动释放
🌍 跨平台桌面、Web、移动端、云——一套语言全搞定
  • 应用领域：Windows 桌面应用 · Web 开发 · 游戏开发（Unity） · 移动应用

⚙️ C# 怎么跑起来的？

C# 不能单独运行，需要 .NET 这个运行平台。可以把 .NET 理解成 C# 的"引擎"——代码写完了，.NET 负责帮你编译和执行。

✍️ 编写 C# 源码→🔧 .NET 编译→⚡ .NET 运行时→🚀 程序运行
写 .cs 文件（人能读懂）转成中间代码（IL）实时翻译成机器指令CPU 执行出结果
  • .NET 框架 = CLR（公共语言运行库）+ BCL（基类库）+ 编程工具
  • C# 代码 → 编译成 IL 中间码 → 运行时 JIT 实时翻译成机器码 → CPU 执行
  • .NET Core：开源、跨平台、基于云，为现代应用场景设计
