什么是数组？

上节课学了字符串——把一串字符当整体操作。但如果要处理的是一组同类数据呢？比如全班40人的成绩、一年12个月的销售额——一个个变量写过去得疯。今天学数组——把同类数据打包在一起，用索引访问。

数组 = 一组相同类型数据的有序集合，通过索引（从0开始）访问每个元素。

数组可以存储任意类型的数据，写法是 类型[]：

数组类型写法示例
整数数组int[]int[] scores = { 85, 90, 78 };
小数数组double[]double[] prices = { 9.9, 19.9 };
字符串数组string[]string[] names = { "张三", "李四" };
字符数组char[]char[] letters = { 'A', 'B', 'C' };
布尔数组bool[]bool[] flags = { true, false };
  • [ ] 表示"这是一个数组"，前面写元素类型
  • 数组一旦创建，大小就固定了，不能动态增删
  • 📖 类比：班级花名册——一行排开，按编号找人

数组的定义与访问

三种定义方式：

CSHARP
// 方式1：声明 + 分配空间
int[] scores = new int[5];          // 5个元素，默认值都是0

// 方式2：声明 + 初始化（最常用）
int[] scores = { 85, 90, 78, 88, 92 };

// 方式3：先分配，再逐个赋值
int[] scores = new int[3];
scores[0] = 85; scores[1] = 90; scores[2] = 78;

访问元素：

CSHARP
int[] scores = { 85, 90, 78, 88, 92 };

int first = scores[0];             // 读取 → 85
scores[2] = 80;                    // 修改 → 78 变 80
Console.WriteLine(scores.Length);  // 长度 → 5

// ⚠️ 索引越界会报错！
// scores[5] = 100;  // ❌ 只有 0~4 五个位置

关于 Length：

  • Length 不是方法（没有括号），是数组自带的属性，直接返回元素个数
  • 索引从 0 开始，最后一个元素是 Length - 1
  • 写 i <= scores.Length 是新手最常见错误——会导致索引越界

for 循环遍历：

CSHARP
for (int i = 0; i < scores.Length; i++)
    Console.WriteLine($"第{i+1}个：{scores[i]}");

用数组存储5个成绩，计算总分、平均分和及格人数。

foreach 遍历

  • foreach 是专门遍历集合的循环，比 for 更简洁
  • 语法拆解：
  foreach ( int    s      in   scores  )
          ↑类型  ↑临时变量 ↑in ↑数组名
          每次循环，当前元素的值赋给 s
CSHARP
int[] scores = { 85, 90, 78 };

// for 版本
for (int i = 0; i < scores.Length; i++)
    Console.WriteLine(scores[i]);

// foreach 版本（不需要索引时推荐）
foreach (int s in scores)
    Console.WriteLine(s);
  • ✅ 适合：求和、找最值、显示列表
  • ⚠️ foreach 中 s 是只读的，不能修改数组元素！要修改用 for
  • 不需要手动写 i++ 和 scores[i]，更简洁安全

上页的成绩求和，用 foreach 重写：

CSHARP
int[] scores = { 85, 90, 78, 88, 92 };

// for 版本 —— 需要手动用 i 取元素
int sum1 = 0;
for (int i = 0; i < scores.Length; i++)
    sum1 += scores[i];
Console.WriteLine($"总分(for)：{sum1}");   // 433

// foreach 版本 —— 直接拿元素，不用管索引
int sum2 = 0;
foreach (int s in scores)
    sum2 += s;
Console.WriteLine($"总分(foreach)：{sum2}"); // 433
只要不关心索引、只遍历每个元素，foreach 就是首选。

数组最值

手工找最大值的思路：先假设第一个是最大值，逐个比较，遇到更大的就替换

CSHARP
int[] scores = { 85, 90, 78, 88, 92 };

int max = scores[0];           // 假设第一个最大
for (int i = 1; i < scores.Length; i++)
{
    if (scores[i] > max)
        max = scores[i];       // 发现更大的就替换
}
Console.WriteLine($"最高分：{max}");   // 92

找最小值把 > 换成 < 即可。

快捷方式——C# 提供了现成方法（需 using System.Linq;）：

方法作用返回值
scores.Max()找最大值元素类型（int → int）
scores.Min()找最小值元素类型（int → int）
scores.Sum()求总和元素类型（int → int）
scores.Average()求平均值double（自动转浮点）
Array.Sort(scores)原地排序void（直接改数组）
CSHARP
int[] scores = { 85, 90, 78, 88, 92 };

int max = scores.Max();       // 92
int min = scores.Min();       // 78
int sum = scores.Sum();       // 433
double avg = scores.Average();// 86.6

Array.Sort(scores);           // 78, 85, 88, 90, 92
💡 考试建议手写循环，日常写代码优先用现成方法。

冒泡排序

🤖 还记得吗：课件2我们用 AI 写了冒泡排序，当时能跑但可能没真懂。今天用原理一行行手写——这正是四步法的最后一步：关掉 AI，自己重写一遍。

排序 = 把一组数据按照从小到大（升序）或从大到小（降序）重新排列。冒泡排序是最直观的排序算法。

核心思想：相邻两个元素比较，如果顺序错了就交换。一轮结束，最大元素"沉"到最后。

以 { 85, 90, 78, 88, 92 } 从小到大排序为例：

第1轮 — 比较相邻元素，大的后移：

85  90  78  88  92
↓
85 < 90? ✅ 不动  →  85, 90, 78, 88, 92
90 > 78? ❌ 交换  →  85, 78, 90, 88, 92
90 > 88? ❌ 交换  →  85, 78, 88, 90, 92
90 < 92? ✅ 不动  →  85, 78, 88, 90, [92] ← 92 沉底！

第2轮 — 只比较前4个（92已就位）：

85 > 78? ❌ 交换  →  78, 85, 88, 90
85 < 88? ✅ 不动
88 < 90? ✅ 不动  →  78, 85, 88, [90, 92] ← 90 沉底！

第3轮 — 只比较前3个：

78, 85, 88 ← 已经有序，无需交换！→ [78, 85, 88, 90, 92]
  • 规律：n 个元素需要 n-1 轮，每轮比较次数递减
每一轮都要把当前还没排好序的元素中的最大值"冒"到最右边——就像水里的气泡，大的总会浮到水面。第 1 轮把最大数沉到最右，第 2 轮把次大数沉到倒数第二……每完成一轮，就有一个数永久就位，后面的轮次不用再管它。

代码实现：

CSHARP
int[] scores = { 85, 90, 78, 88, 92 };

// 冒泡排序（从小到大）
for (int i = 0; i < scores.Length - 1; i++)          // 外层：第几轮
{
    // 内层：每轮比较 (长度-1-i) 次
    // i=0时比较4次，i=1时比较3次...因为后面已排序的不再比较
    for (int j = 0; j < scores.Length - 1 - i; j++)
    {
        if (scores[j] > scores[j + 1])                 // 前 > 后？交换
        {
            int temp = scores[j];                       // 三变量交换法
            scores[j] = scores[j + 1];
            scores[j + 1] = temp;
        }
    }
}
// 结果：78, 85, 88, 90, 92

捷径（但不要求手写）：

CSHARP
Array.Sort(scores);            // 从小到大
Array.Reverse(scores);         // 翻转顺序
  • Array.Sort(scores) — 原地排序，直接修改数组，从小到大排列
  • Array.Reverse(scores) — 原地翻转，把数组元素首尾颠倒
  • 两者都无返回值（void），排序结果直接体现在原数组上

排序后怎么用？

CSHARP
// ① 正序输出（从小到大）

    Console.Write(s + " ");

值类型与引用类型

用生活比喻理解"值"和"引用"

  • 值类型 = 复印一张纸给你。你在你的纸上改，不影响我的原件
  • 引用类型 = 给你我家的门牌号。你按门牌号找到我家，改了东西，我也受影响

用代码验证：

CSHARP
// 值类型：各有一份副本，互不影响
int a = 10;
int b = a;     // b 拿到了 a 的复印件
b = 20;        // 改复印件，a 还是 10 ✅

// 引用类型：指向同一个地方
int[] arr1 = { 1, 2, 3 };
int[] arr2 = arr1;    // arr2 拿到的是门牌号，指向同一个数组
arr2[0] = 99;         // 通过门牌号改了数组
Console.WriteLine(arr1[0]);  // 99！arr1 也变了 ⚠️
📌 数组是引用类型。arr1 和 arr2 存的是同一个地址，改 arr2 就是在改 arr1。

"引用"到底是什么？

数组变量本身存的不是数据，而是一个地址（门牌号）。真正的数据存在内存的另一块区域里：

arr1 →  [地址0x100] →  {1, 2, 3}  ← 真正的数据
arr2 →  [地址0x100] ↗              ← 复制的也是同一个地址

arr2[0] = 99 → 改了数据 → arr1[0] = 99  ← 同一个地方，一起变了
引用 = 门牌号 = 内存地址。多个变量拿着同一个地址，改一处全变。

总结对比：

值类型引用类型
比喻复印件门牌号
改了之后互不影响牵一发动全身
代表类型int、double、bool数组、string、class
默认值0、falsenull
赋值行为复制数据本身复制地址（指向原数据）

本节知识梳理

今天我们一起啃下了这些核心内容：

  • 什么是数组？：一组相同类型数据的集合，用下标访问
  • 数组的定义与访问：类型[] 名 = new 类型[长度]; 下标从 0 开始
  • foreach 遍历：逐个取出元素，不用管下标
  • 数组最值：先假设第 0 个是极值，逐个比较更新
  • 冒泡排序：相邻两两比，大的往后冒，外层控制轮数
  • 值类型与引用类型：int 等是值类型（复制值），数组/类是引用类型（复制地址）
  • 多维数组：int[,] 二维表，用两个下标定位
