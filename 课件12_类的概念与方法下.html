方法重载

上节课写了 Add(int a, int b)，两个整数相加。现在需求来了：

  • 两个整数相加 → Add(3, 5) ✅ 已有
  • 三个整数相加 → 怎么办？再写一个方法叫 AddThree？
  • 两个小数相加 → 叫 AddDouble？

名字会越来越乱，调用方得记一堆方法名。能不能都叫 Add？

答案就是方法重载——同一个方法名，参数不同，各干各的。调用方只需写 Add(...)，系统根据传的参数自动选对的版本。

现实类比：「洗」一个动词，洗什么配什么

场景方法参数
洗脸洗(水)只需要水
洗衣服洗(衣服, 洗衣液)需要衣服+洗衣液
洗碗洗(碗, 洗洁精)需要碗+洗洁精

三种"洗"，名字一样参数不同——这就是重载。

CSHARP
class Calculator
{
    public int Add(int a, int b) { ... }          // 两个整数
    public int Add(int a, int b, int c) { ... }    // 三个整数
    public double Add(double a, double b) { ... }  // 两个小数
}
  • 好处：调用方只需记住一个方法名，系统根据给的参数自动匹配
  • 条件：方法名相同，参数列表不同（个数或类型）
  • 只改返回值不算重载，编译器分不清

构造方法重载

CSHARP
class Student
{
    public string name;
    public int age;
    public double score;

    // 重载1：完整构造——全部字段
    public Student(string name, int age, double score)
    {
        this.name = name; this.age = age; this.score = score;
    }

    // 重载2：简化构造——只有姓名
    public Student(string name)
    {
        this.name = name;
        this.age = 0;
        this.score = 0;
    }

    // 重载3：默认构造——什么都不给
    public Student() { }
}
CSHARP
Student s1 = new Student("张三", 18, 85);  // 给什么参数，自动匹配哪个构造方法
Student s2 = new Student("李四");           // 只给姓名
Student s3 = new Student();                // 什么都不给
  • 同一个 new Student( )，参数不同就走不同的构造方法
💡 既然有对象初始化器 new Student { name="张三" }，还需要构造函数重载吗？需要！看三个场景——

场景一：强制传参。 初始化器可以不写 age（默认 0），但业务上学生必须有年龄。

CSHARP
// ❌ 初始化器：漏了 age，没人提醒
var s = new Student { name = "张三" };  // age = 0，静默通过

// ✅ 构造函数：不传 age 直接编译报错
public Student(string name, int age) { ... }
var s = new Student("张三");  // ❌ 编译错误：缺少参数

场景二：做校验。 年龄不能为负，初始化器赋值完了才发现不了。

CSHARP
// ❌ 初始化器：负数静默通过
var s = new Student { name = "张三", age = -5 };  // 没人管

// ✅ 构造函数：当场拦截
public Student(string name, int age)
{
    if (age < 0) throw new Exception("年龄不能为负！");
    this.name = name; this.age = age;
}

场景三：private 字段。 初始化器只能碰 public 的字段，private 的根本看不见。

CSHARP
class Student
{
    private string id;      // 学号，外部不能乱改
    public string name;

    public Student(string id, string name)
    {
        this.id = id;       // ✅ 构造函数可以访问 private
        this.name = name;
    }
}
// var s = new Student { id = "S001", name = "张三" };  // ❌ 编译错误！
💬 初始化器是"简装版"，构造函数是"精装版"——要强制、要校验、要保密就上构造函数。

课堂练习1 — 方法重载

用方法重载改造一个打印工具——不管传什么类型的参数，都叫同一个方法名 Print。

代码示例（老师示范讲解）

CSHARP
class Printer
{
    public void Print(int value)
    {
        Console.WriteLine($"整数：{value}");
    }

    public void Print(double value)
    {
        Console.WriteLine($"小数：{value:F2}");
    }

    public void Print(string value)
    {
        Console.WriteLine($"字符串：「{value}」");
    }
}
CSHARP
Printer p = new Printer();
p.Print(100);       // 整数：100
p.Print(3.14);      // 小数：3.14
p.Print("Hello");   // 字符串：「Hello」
  • 动手：给 Printer 再加一个 Print(bool value) 重载，输出「布尔值：True/False」
💬 解释说明
  • 三个 Print 方法名完全一样，C# 靠参数类型自动区分——传 int 走第一个，传 string 走第三个
  • 这就是重载的核心价值：调用方只管写 p.Print(...)，不用记 PrintInt、PrintDouble、PrintString

static — 属于类，不属于对象

来看一段代码，注意 static 关键字：

CSHARP
class Classroom
{
    public string studentName;           // 普通字段：每人不同
    public static int temperature = 26;  // static 字段：全班共用
}
CSHARP
// 普通字段：必须先 new 对象才能用
Classroom c1 = new Classroom();
c1.studentName = "张三";       // ✅ 通过对象访问

// static 字段：直接用类名访问，不需要 new
Classroom.temperature = 28;    // ✅ 类名.字段名
Console.WriteLine(Classroom.temperature);  // 28

为什么？类比理解：

  • 每个学生都有自己的一支铅笔（普通字段）——你的铅笔和别人不一样
  • 但教室的空调遥控器只有一个（static 字段）——全教室共用，谁拿起来都能调温度
普通成员static 成员
归属于每个对象各有一份整个类共享一份
比喻铅笔（自己的）空调遥控器（共用的）
调用方式对象.成员类名.成员
需要 new？必须先 new 对象直接用，不需要 new
  • 你之前就在用 static！Console.WriteLine()、int.Parse() 都是 static 方法——从来没有 new Console() 过，对吧？

static 示例 — 学生计数器

CSHARP
class Student
{
    public string name;
    public static int totalCount = 0;      // 全班共享一份

    public Student(string name)
    {
        this.name = name;
        totalCount++;                      // 每创建一个学生，计数+1
    }

    public static void ShowTotal()
    {
        Console.WriteLine($"共有 {totalCount} 名学生");
    }
}
CSHARP
Student s1 = new Student("张三");
Student s2 = new Student("李四");
Student.ShowTotal();   // 共有 2 名学生（类名.方法名，无需 new）
// 每个 new Student(...) 执行时都会 totalCount++，因为 static 是共享的

课堂练习2 — 最大公约数与质数判断

定义静态工具类，包含求最大公约数和判断质数的方法，直接用类名调用，体会 static 的便利。

代码示例（老师示范讲解）

CSHARP
class MathTool
{
    // GCD（最大公约数）：两个数都能整除的最大数
    public static int GCD(int a, int b)
    {
        while (b != 0)
        {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }

    // 质数：只能被1和自己整除，如 2、3、5、7、11...
    public static bool IsPrime(int num)
    {
        if (num < 2) return false;
        for (int i = 2; i * i <= num; i++)
            if (num % i == 0) return false;
        return true;
    }
}
CSHARP
// 直接用 类名.方法名()，省去 new 的步骤
Console.WriteLine(MathTool.GCD(48, 18));    // 6
Console.WriteLine(MathTool.IsPrime(7));     // True
Console.WriteLine(MathTool.IsPrime(10));    // False
  • 动手：用 MathTool.GCD() 求 24 和 36 的最大公约数，看看结果
💬 解释说明
  • GCD 和 IsPrime 都是 static——不需要创建对象，像使用 Console.WriteLine() 一样直接 MathTool.GCD(...) 就能调用
  • static 方法的好处：像工具箱里的工具，随拿随用，不用先"买一套新工具箱"
  • IsPrime 的循环条件 i * i <= num 是质数判定的优化写法：如果 num 是合数，必有一个因子 ≤ √num

本节知识梳理

今天我们一起啃下了这些核心内容：

  • 方法重载：同名不同参数（个数/类型），调用时按实参匹配
  • 构造方法重载：一个类写多个构造方法，方便用不同方式创建
  • static — 属于类，不属于对象：static 成员直接用 类名. 访问，不依赖实例
  • static 示例 — 学生计数器：用 static 字段统计一共创建了多少学生
💡 接下来是「综合练习」——不再是单个知识点的小练习，而是把上面这些串起来解决一个真实小任务。先自己动手写，实在卡住再看答案。

综合练习 — 商品库存管理

设计 Product 类实现入库操作，用构造方法重载和方法重载灵活管理商品。

期望输入：

商品A：单价19.9，初始库存10
商品B：单价5.0，初始库存50

期望输出：

--- 入库前 ---
商品A：¥19.9 × 10件  总价：¥199.0
商品B：¥5.0 × 50件  总价：¥250.0
共有 2 种商品

--- 操作 ---
商品A 入库30件 → 库存：40
商品A 入库（默认+1件）→ 库存：41
商品A 按比例50%补货 → 库存：61
商品B 入库20件 → 库存：70

--- 入库后 ---
商品A：¥19.9 × 61件  总价：¥1213.9
商品B：¥5.0 × 70件  总价：¥350.0
当前共有 2 种商品
  • 三个构造重载：完整（名称+价格+库存）、精简（名称+价格，库存默认0）、默认（空）
  • 三个入库方法重载：Restock(int qty) 指定数量、Restock() 默认+1、Restock(double rate) 按比例补货
  • static int TotalTypes 统计商品种类
  • ___ 是需要你补全的地方

class Product
{
    public string name;
    public double price;
    public int stock;
    public static int TotalTypes = 0;

    public Product(string name, double price, int stock)
    {
        this.name = name;
        this.price = price;
        this.stock = stock;
        TotalTypes++;
    }

    public Product(string name, double price)
    {
        this.name = name;
        this.price = price;
        this.stock = 0;
        TotalTypes++;
    }

    public Product() { }

    public void Restock(int qty)
    {
        stock += qty;
        Console.WriteLine($"{name} 入库{qty}件 → 库存：{stock}");
    }

    public void Restock()
    {
        Restock(1);
    }

    public void Restock(double rate)
    {
        int qty = (int)(stock * rate);
        Restock(qty);
    }

    public void Show()
    {
        Console.WriteLine($"{name}：¥{price} × {stock}件  总价：¥{price * stock:F1}");
    }
}

拔高题（选做，自己写，不填空）

需求：用递归写一个方法 Factorial(n)，返回 n 的阶乘（n! = n × (n-1) × … × 1，0! = 1）。
要求：自己写递归方法并在 Main 里调用，不能用循环代替。
CSHARP
static long Factorial(int n)
{
    if (n <= 1) return 1;            // 递归出口
    return n * Factorial(n - 1);     // 自己调用自己
}
// Main 中：
int n = int.Parse(Console.ReadLine());
Console.WriteLine($"{n}! = {Factorial(n)}");
