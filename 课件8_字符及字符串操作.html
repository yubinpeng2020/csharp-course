方法说明示例

Substring(start, len)从 start 取 len 个str.Substring(0, 5) → "Hello"

拆分 — Split

CSHARP
// Split：按分隔符拆成数组
string fruits = "苹果,香蕉,橘子";
string[] arr = fruits.Split(',');
// 结果：arr[0]="苹果", arr[1]="香蕉", arr[2]="橘子"

链式调用

多个字符串方法可以像火车一样连起来写，从左到右依次执行。

CSHARP
string answer = Console.ReadLine()
                       .Trim()      // ① 去掉前后空格
                       .ToLower();  // ② 转为小写
if (answer == "yes") { ... }        // ③ 比较（不区分大小写）
  • 等价于拆成三行：string raw = ReadLine(); string t = raw.Trim(); string l = t.ToLower();

为什么可以链式调用？

Trim()、ToLower()、Replace() 这些方法的返回值都是 string——既然方法吐出的是字符串，那紧接着就能对这个结果继续调方法。

Console.ReadLine()   →  返回 string（用户输入）
       .Trim()       →  返回 string（去掉空格后）
       .ToLower()    →  返回 string（转小写后）
  • 链式写法更简洁，但别太长——超过 3 个就考虑换行或拆开

课堂练习1 — 查找与截取

解析邮箱地址：检查是否含@，拆分用户名和域名，判断邮箱类型。用到 Contains / IndexOf / Substring / EndsWith。

代码示例（老师示范讲解）

CSHARP
Console.Write("请输入邮箱地址：");
string email = Console.ReadLine().Trim();

if (email.Contains("@"))
{
    int atIndex = email.IndexOf("@");
    string username = email.Substring(0, atIndex);
    string domain = email.Substring(atIndex + 1);

    Console.WriteLine($"用户名：{username}");
    Console.WriteLine($"域名：{domain}");

    if (domain.EndsWith("qq.com"))
        Console.WriteLine("这是QQ邮箱");
    else if (domain.EndsWith("163.com"))
        Console.WriteLine("这是163邮箱");
    else if (domain.EndsWith("gmail.com"))
        Console.WriteLine("这是Gmail邮箱");

    if (username.Length == 0)
        Console.WriteLine("⚠️ 用户名为空！");
}
else
{
    Console.WriteLine("这不是一个有效的邮箱地址！");
}
  • 动手：加上判断域名是否以 www. 开头
💬 解释说明
  • Contains("@") 判断邮箱是否合法 — 先检查有没有 @
  • IndexOf("@") 找到 @ 的位置，Substring 根据位置截取用户名和域名
  • EndsWith 判断邮箱服务商
  • 口诀：先 Contains 判断，再 IndexOf 定位，最后 Substring 截取

课堂练习2 — 清洗与拆分

输入一句带空格和标点的英文，清洗后按空格拆分，统计单词数。用到 Trim / Replace / Split / ToLower / Length。

代码示例（老师示范讲解）

CSHARP
Console.Write("请输入一句英文：");
string raw = Console.ReadLine();

// 链式调用：去空格、去标点、转小写
string cleaned = raw.Trim()
                    .Replace(",", "")
                    .Replace(".", "")
                    .Replace("!", "")
                    .ToLower();

string[] words = cleaned.Split(' ');           // 按空格拆分
Console.WriteLine($"共 {words.Length} 个单词：");
foreach (string w in words)
    Console.WriteLine($"  · {w}");
  • 动手：统计每个单词的长度
💬 解释说明
  • Replace 连续调用去掉标点 — 这就是链式调用的威力
  • Split(' ') 按空格切成数组，Length 统计单词数
  • foreach 逐词输出（循环见课件7）

字符串相等比较

CSHARP
string a = "hello";
string b = "Hello";

// ==：比较内容是否相同（区分大小写，日常最常用）
Console.WriteLine(a == b);                  // false

// Equals：比较内容，可指定忽略大小写
Console.WriteLine(a.Equals(b));             // false
Console.WriteLine(a.Equals(b, StringComparison.OrdinalIgnoreCase)); // true ⭐
方式用法推荐场景
==a == b日常比较，区分大小写
Equals(忽略大小写)a.Equals(b, OrdinalIgnoreCase)用户名、验证码等不区分大小写
CompareToa.CompareTo(b)排序用，返回 -1/0/1，后续课件讲

格式化字符串

CSHARP
// 控制小数位数
double pi = 3.1415926;
Console.WriteLine($"{pi:F2}");        // "3.14"（保留2位）

// 补零
Console.WriteLine($"{3:D5}");         // "00003"（补到5位）

D5补零到5位$"{3:D5}" → "00003"
P百分比$"{0.85:P}" → "85.00%"
C货币格式$"{100:C}" → "￥100.00"

StringBuilder — 高效拼接

💡 循环里大量拼接字符串时，string 每次都会创建新对象，StringBuilder 在原缓冲区上追加，性能更高。
方式特点适用场景
string 拼接每次创建新对象，产生垃圾少量拼接（< 5 次）
StringBuilder在内部缓冲区追加，不产生垃圾循环中拼接、大量拼接
CSHARP
using System.Text;

// ❌ 循环里用 string 拼接 — 每次都创建新字符串
string s = "";
for (int i = 0; i < 1000; i++)
    s += i.ToString() + ",";  // 1000 次创建新对象

// ✅ 用 StringBuilder — 在缓冲区上追加
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++)
    sb.Append(i).Append(",");   // 始终操作同一缓冲区
string result = sb.ToString();   // 最后再转成 string

常用方法：

  • Append(值) — 追加内容
  • AppendLine(值) — 追加一行（自动换行）
  • Insert(位置, 值) — 在指定位置插入
  • Remove(起始, 长度) — 删除一段
  • ToString() — 转回 string
💬 日常写代码，少量拼接用 + 或 $"" 就够了。只有循环里大量拼接时才需要 StringBuilder——别过度优化。

本节知识梳理

今天我们一起啃下了这些核心内容：

  • 字符串的声明与拼接：string s = "..."; 用 + 或 $"{}" 拼接
  • 字符串长度与判空：.Length 取长度，string.IsNullOrEmpty() 判断是否为空
  • 截取子串 — Substring：.Substring(起,长) 切出一段
  • 替换 — Replace：.Replace(旧,新) 把某段换成另一段
  • 拆分 — Split：.Split(分隔符) 切成字符串数组
  • 大小写转换与去空格：.ToUpper()/.ToLower()/.Trim()
  • 格式化字符串：$"{}" 插值，或 string.Format 占位
💡 接下来是「综合练习」——不再是单个知识点的小练习，而是把上面这些串起来解决一个真实小任务。先自己动手写，实在卡住再看答案。
