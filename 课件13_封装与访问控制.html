为什么要封装？

什么是封装？ 一句话：把数据藏起来，只通过指定的方法操作。

还记得课件11的"大盒子"吗？类把字段和方法打包在一起——封装更进一步：给每个字段贴上"权限标签"。外面的代码想碰 age？必须走 SetAge() 这道安检门，不能直接伸手进去乱摸。

课件11：public 字段 — 盒子上全是洞，随便掏

┌────────── 类：Student ─────────┐
│                                │
│  👋 name (public)  ←随便摸→    │
│  👋 age (public)   ←随便摸→    │
│  👋 score (public) ←随便摸→    │
│                                │
│  ⚙️ SayHello()                 │
└────────────────────────────────┘
      ↑ 外部代码直接 s.age = -5，没人拦


课件13：private 字段 — 安了密码锁，只能走前台

┌────────── 类：Student ─────────┐
│                                │
│  👋 name (public)  ←可以碰     │
│  🔒 age (private)  ←🔐上锁了！  │
│  🔒 score (private)←🔐上锁了！  │
│                                │
│  🛂 SetAge(值)  ←唯一通道      │
│  🛂 GetAge()    ←唯一通道      │
│  ⚙️ SayHello()                 │
└────────────────────────────────┘
      ↑ 外部只能走 SetAge()，里面可以检查"年龄不能为负"

类比：遥控器——你按"音量+"就行，不需要知道里面的电路怎么走的。外壳把元件封装在内部，按钮是唯一可以碰的地方。

不封装会出什么问题？ 课件11-12我们写的类，字段全是 public：

CSHARP
Student s = new Student();
s.age = -5;        // 年龄-5？没人拦
s.score = 9999;    // 9999分？一样通过

本课件的目标：给数据装上安检门。

public（公开）vs private（私有）

上页说"贴权限标签"，这个标签在 C# 里叫访问修饰符——它决定了谁能碰这个字段或方法。C# 有多个访问级别，本节课先掌握最核心的两个。后面课件还会讲 protected（子类可用），但 public 和 private 覆盖了 90% 的场景。

修饰符含义比喻
public公开的，谁都能用门牌号
private私有的，仅类内部可用日记本

来看代码——同一个类，名字公开、年龄和成绩私有：

CSHARP
class Student
{
    public string name;         // public：谁都能访问
    private int age;            // private：只有类内部能访问
    private double score;
}
CSHARP
Student s = new Student();
s.name = "张三";       // ✅ public，外部可以
// s.age = 18;         // ❌ private，外部不能直接碰！
// s.score = 85;       // ❌ 同上

private 了就不能碰了？——通过公开的方法安全访问

把字段设为 private 之后，外部不能直接 s.age = 18，但可以通过类自己提供的 public 方法来操作——方法内部可以做检查，拒绝不合理的值。

CSHARP
class Student
{
    private int age;

    // Set 方法：设置值，带检查
    public void SetAge(int value)
    {
        if (value >= 0 && value <= 150)
            age = value;
        else
            Console.WriteLine($"年龄 {value} 不合法，已拒绝");
    }

    // Get 方法：读取值
    public int GetAge()
    {
        return age;
    }
}
CSHARP
Student s = new Student();
s.SetAge(18);     // ✅ 合法
s.SetAge(-5);     // ❌ 输出：年龄 -5 不合法，已拒绝
// s.age = -5;    // ❌ 编译也不通过，因为 age 是 private
💬 只是挡一个负数？听起来有点小题大作。再看一个场景——改年龄时自动更新"是否成年"：
CSHARP
class Student
{
    private int age;
    public bool IsAdult { get; private set; }  // 外部只能读，不能改

    public void SetAge(int value)
    {
        age = value;
        IsAdult = value >= 18;   // 🎯 联动：年龄一改，"成年"状态自动刷新
    }
}

如果 age 是 public，别人直接 s.age = 15 绕过 SetAge，IsAdult 还是 true——数据就乱了。封装不是脱裤子放屁，是把"改数据"和"相关联反应"锁在一条通道里，缺一不可。

属性（Property）— 更优雅的 Set/Get

Set/Get 方法好用，但每次写两个方法太啰嗦。C# 提供了属性：

CSHARP
class Student
{
    private int age;

    public int Age        // 属性名用 Pascal 命名
    {
        get { return age; }               // 读的时候执行
        set                                 // 写的时候执行
        {
            if (value >= 0 && value <= 150)
                age = value;
            else
                Console.WriteLine($"年龄 {value} 不合法，已拒绝");
            // ↑ 不合法的值被拦截，age 保持不变
        }
    }
}
CSHARP
Student s = new Student();
s.Age = 18;              // 看起来像字段赋值 → 实际调用了 set
s.Age = -5;              // 输出：年龄 -5 不合法，已拒绝
Console.WriteLine(s.Age); // 18，读到的是旧值（-5被拒了）
  • value 是关键字，代表 = 右边传进来的值
  • 属性 = 带保安的字段——外表是字段，内部有逻辑

不需要检查时，还有更短写法——自动属性

如果只是简单存取、不用校验，一行就能搞定：

CSHARP
class Student
{
    public string Name { get; set; }          // 读+写都公开
    public int Age { get; private set; }       // 读公开，写仅内部
    public double Score { get; set; }
}
CSHARP
Student s = new Student();
s.Name = "张三";       // ✅ set 公开
s.Age = 18;            // ❌ private set，外部不能赋值！
// Age 只能在构造方法等类内部代码中赋值
  • 自动属性 = 编译器帮你生成隐藏的 private 字段，不用手写
  • { get; private set; } 的经典场景：余额、密码——外部谁都能看，但只有类内部能改

表达式体成员（=>）— 一行搞定

{ return ...; } 写多了手酸？C# 提供了 => 简写——方法、属性、甚至构造方法都能缩成一行。

=> 读作"结果是"，语法：成员 => 表达式。

方法：

CSHARP
// 传统
public double GetAverage()
{
    return GetTotal() / 3;
}

// => 简写
public double GetAverage() => GetTotal() / 3;

只读属性：

CSHARP
// 传统
public double Total
{
    get { return chinese + math + english; }
}

// => 简写（连 get { } 都省了）
public double Total => chinese + math + english;

属性简写 + 方法简写一起上：

CSHARP
class Student
{
    public double Chinese;
    public double Math;
    public double English;

    public double Total => Chinese + Math + English;       // 只读属性
    public double GetAverage() => Total / 3;                // 方法
    public bool IsPassed() => GetAverage() >= 60;           // 方法
}

适用条件： 方法体只有一行 return 或一行语句时才能用。多行逻辑、if-else 绕弯的还是老老实实用 { }。

课堂练习1 — 密码强度校验

用属性封装密码，要求长度 ≥ 6 位才接受，太短直接拒绝。

代码示例（老师示范讲解）

CSHARP
class User
{
    private string password;
    public string Username { get; set; }

    public string Password
    {
        get => password;
        set
        {
            if (value.Length >= 6)
                password = value;
            else
                Console.WriteLine($"密码太短（{value.Length}位），至少需要6位");
        }
    }

    public string Info => $"{Username}，密码已设置：{(password != null ? "是" : "否")}";
}
CSHARP
User u = new User { Username = "admin", Password = "123456" };
Console.WriteLine(u.Info);   // admin，密码已设置：是
u.Password = "123";          // 密码太短（3位），至少需要6位
Console.WriteLine(u.Info);   // admin，密码已设置：是（123被拒，仍是123456）
  • 动手：试试 Password = "abc" 和 Password = "abcdefgh"，对比结果
💬 解释说明
  • set 里不只看数值范围，还能检查字符串长度——封装不限于数字
  • value 在 string 类型时就是传进来的字符串，value.Length 直接取长度
  • value 是 C# 关键字，代表 = 右边传进来的值；字符串时就是字符串，数字时就是数字
  • 封装不限于数值范围：字符串长度、格式校验、甚至调用外部接口判断都可以放在 set 里
  • 校验不通过时不执行赋值，原值保持不变

本节知识梳理

今天我们一起啃下了这些核心内容：

  • 为什么要封装？：把内部细节藏起来，只暴露安全的访问口，防乱改
  • public（公开）vs private（私有）：public 谁都能用，private 只有自己类里能用
  • 属性（Property）— 更优雅的 Set/Get：public 类型 名 {get;set;} 自动管读写
  • 表达式体成员（=>）— 一行搞定：=> 表达式 一行写方法/属性，更简洁
💡 接下来是「综合练习」——不再是单个知识点的小练习，而是把上面这些串起来解决一个真实小任务。先自己动手写，实在卡住再看答案。

综合练习 — 学生成绩管理器

三门成绩封装为属性（0-100），总分/平均分/等级用 => 写为只读属性。

期望输入：

张三 语文85 数学90 英语78
（尝试设置 Chinese = 120 —— 应被拦截）

期望输出：

张三: 总分253 平均84.3 等级B
成绩120无效（被拦截）
  • 每科成绩的 set 都要检查 value >= 0 && value <= 100
  • Total、Average、Grade 都是只读，用 => 最简洁
  • ___ 是需要你补全的地方

拔高题（选做，自己写，不填空）

需求：自己写一个 Thermometer（温度计）类，用属性存温度，要求温度只能在 0~50℃ 之间，越界就提示"温度异常"并保持原值。
要求：完整定义类（属性 set 里做校验）+ Main 演示，不能用现成模板。
CSHARP
class Thermometer
{
    private double t;
    public double Temp
    {
        get => t;
        set
        {
            if (value >= 0 && value <= 50) t = value;
            else Console.WriteLine("温度异常，已忽略");
        }
    }
}
class Program
{
    static void Main()
    {
        Thermometer th = new Thermometer();
        th.Temp = 25;
        th.Temp = 99;   // 越界，保持原值
        Console.WriteLine($"当前温度：{th.Temp}");
    }
}
