什么是类型转换？

类型转换就是把一种数据类型变成另一种，让不同类型的数据可以互相配合。

什么时候需要：

  • 计算时类型不匹配：
CSHARP
  int count = 5;
  double price = 9.9;
  double total = count * price;   // int 自动转为 double
  • 用户输入都是 string，必须转成数字才能计算：
CSHARP
  string input = Console.ReadLine();  // "18"
  int age = int.Parse(input);         // string → int

两种方式：

方式谁来干什么时候
隐式转换（自动）编译器自动完成小 → 大，不会丢数据
显式转换（手动）你自己写代码大 → 小，或 string → 数字
"范围"就是能装多少东西：int 装整数（±21亿），double 能装带小数点的更大数字。int → double = 小杯子倒进大桶，安全。

隐式转换 — 自动类型转换

  • 小范围 → 大范围，编译器自动完成，安全
CSHARP
  int a = 100;
  double b = a;        // int → double，b = 100.0
  long c = a;          // int → long
  float d = a;         // int → float
  • 转换路线：int → long → float → double
  • 反向不行！大转小必须手动
原类型可自动转为示例
intdouble、float、longdouble x = 5; ✅
floatdoubledouble x = 3.14f; ✅
charint、long、float、doubleint x = 'A'; ✅ (x=65)
double❌ 不能自动转 intint x = 3.14; ❌ 编译报错
  • 记住：整数可以自动变小数，小数不能自动变整数
  • char 可以自动转 int，因为每个字符在计算机里都有一个数字编号（'A' = 65），这就是 Unicode 编码
  • ⚠️ bool 不能和任何数值类型互转：int x = (int)true; ❌，bool b = 1; ❌
  • 需要转换时用：int n = flag ? 1 : 0; 或 bool ok = (score >= 60);

显式转换 — 强制类型转换

  • 大范围 → 小范围，需要手动指定，可能丢失精度
CSHARP
  double pi = 3.14159;
  int x = (int)pi;       // 强制转换，x = 3，小数被截断！
  
  double price = 9.99;
  int yuan = (int)price; // yuan = 9，不是四舍五入
  • 语法：(目标类型)表达式
  • ⚠️ 强制转换是截断，不是四舍五入

精度丢失示例

CSHARP
byte a;
int b = 298;
a = (byte)b;
// b = 298（int占4字节）
// a = 42  （byte只取最低1字节，高位数据丢失！）
  • 298 的二进制：00000000 00000000 00000001 00101010
  • 截取最低字节：00101010 = 42
  • ⚠️ 强制转换前要确保目标类型装得下，否则结果不可信
💡 回顾课件3：byte 只有 8 位二进制（上限 255），298 超出范围，高位被丢弃

课堂练习1 — 类型转换

练习自动转换和强制转换，理解 int↔double 互转的规则和精度问题。

代码示例（老师示范讲解）

CSHARP
// 自动转换
int count = 10;
double total = count;     // int → double，安全
Console.WriteLine($"total = {total}");   // 输出：10

// 强制转换
double price = 9.99;
int yuan = (int)price;    // double → int，截断小数
Console.WriteLine($"yuan = {yuan}");      // 输出：9

// 四舍五入技巧
int rounded = (int)(price + 0.5);  // 9.99+0.5=10.49 → 10
Console.WriteLine($"四舍五入 = {rounded}");  // 输出：10
  • 动手：把 price 改成 3.14、7.8，观察 yuan 和 rounded 的变化
💬 解释说明
  • (int) 强制转换是截断小数，不是四舍五入
  • 四舍五入技巧：(int)(数 + 0.5) — 先加0.5再截断
  • 小→大自动转，大→小必须手动加 (int)

string ↔ 数值互转

string → 数值：Parse

用户输入都是 string，计算前必须转换：

CSHARP
Console.Write("请输入年龄：");
string input = Console.ReadLine();    // 得到 "18"（string）
int age = int.Parse(input);           // string → int
目标类型方法示例
intint.Parse()int n = int.Parse("123");
doubledouble.Parse()double d = double.Parse("3.14");
floatfloat.Parse()float f = float.Parse("9.9");
boolbool.Parse()bool b = bool.Parse("true");

数值 → string：ToString

反过来，把数字变成文字显示：

CSHARP
int score = 95;
string s = score.ToString();   // "95"

double pi = 3.14;
string s2 = pi.ToString();     // "3.14"

更常用的是 $ 插值，自动调用 ToString：

CSHARP
int a = 10, b = 20;
string result = $"{a} + {b} = {a + b}";  // "10 + 20 = 30"

本节知识梳理

今天我们一起啃下了这些核心内容：

  • 什么是类型转换？：把一种类型的数据变成另一种类型
  • 隐式转换 — 自动类型转换：小范围转大范围（如 int→double）自动完成
  • 显式转换 — 强制类型转换：大范围转小范围需 (类型) 强转，可能丢精度
  • string ↔ 数值互转：int.Parse() / double.Parse() 字符串转数，ToString() 数转字符串
💡 接下来是「综合练习」——不再是单个知识点的小练习，而是把上面这些串起来解决一个真实小任务。先自己动手写，实在卡住再看答案。

拔高题（选做，自己写，不填空）

需求：让用户输入一串用逗号分隔的数字（如 3, 7, 2.5, 10），程序输出它们的总和与个数。
要求：自己写——用 Split 拆串、double.Parse 逐个转换、用循环累加，不能用现成模板。
提示：string[] parts = input.Split(','); 然后遍历 parts，每个用 double.Parse(p.Trim()) 转换。
CSHARP
string input = Console.ReadLine();
string[] parts = input.Split(',');
double sum = 0;
foreach (string p in parts)
    sum += double.Parse(p.Trim());
Console.WriteLine($"共 {parts.Length} 个数，总和 = {sum}");
