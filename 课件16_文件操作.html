为什么需要文件操作？

学了15个课件，你写的程序有一个致命缺陷——一关一闭，片甲不留。成绩、分数、账号密码，全在内存里烧成灰。

文件操作就是要打破这个魔咒：数据存到硬盘，十年后打开还在。

你的程序                       硬盘上的文件
┌─────────────┐    写入→     ┌─────────────┐
│  Console    │  ←── 读取    │  data.txt   │
│  List<T>    │              │  save.json  │
│  Dictionary │              │  log.csv    │
└─────────────┘              └─────────────┘

现实世界到处是它：

你用过的软件背后就是文件操作
记事本保存文字→ .txt
教务系统成绩单→ 文件/数据库
王者荣耀角色装备→ 存档文件
微信聊天聊天记录→ 本地数据库文件
VS自己你写的 .cs 代码→ 就是文件！

一句话：读取是硬盘 → 程序，写入是程序 → 硬盘。两个方向，两个关键词。

文件操作的两个核心类

C# 用两个类搞定所有文件读写，一个管写、一个管读：

类方向比喻核心方法
StreamWriter程序 → 文件把字写在纸上Write() WriteLine()
StreamReader文件 → 程序看书上的字ReadLine() ReadToEnd()

StreamWriter — 写入文件

注意：StreamWriter 和 StreamReader 都在 System.IO 命名空间里，文件开头要加 using System.IO;。

完整可运行的代码——运行后在项目文件夹里就能看到生成的 test.txt（和 .cs 文件同级）：

CSHARP
using System.IO;  // 文件操作都在这个命名空间

class Program
{
    static void Main()
    {
        StreamWriter sw = new StreamWriter("test.txt");
        sw.WriteLine("Hello");
        sw.Close();      // 必须手动关
    }
}

但有个坑——万一忘了 Close()：

CSHARP
StreamWriter sw = new StreamWriter("test.txt");
sw.WriteLine("Hello");
// 忘了 sw.Close() —— 文件一直锁着，关掉程序才释放 ⚠️

后果：文件被你的程序占着，别的程序打不开，你自己都删不掉。

好消息：用 using 解决——离开 { } 自动关闭：

CSHARP
using (StreamWriter sw = new StreamWriter("test.txt"))
{
    sw.WriteLine("Hello");
}  // ← 到这自动 Close()，天塌了都关
💡 从这页开始，所有文件操作代码都用 using 包裹。

WriteLine 写完自动换行，Write 不换行：

CSHARP
using (StreamWriter sw = new StreamWriter("test.txt"))
{
    sw.Write("Hello");      // 不换行
    sw.Write("World");      // → HelloWorld
    sw.WriteLine("第一行");  // 换行
    sw.WriteLine("第二行");  // → 第一行\n第二行
}

默认每次写入会清空原文件，加 true 变成追加：

CSHARP
// 覆盖写入（默认）
using (StreamWriter sw = new StreamWriter("score.txt"))
    sw.WriteLine("张三 85");
// score.txt → "张三 85"

// 追加写入
using (StreamWriter sw = new StreamWriter("score.txt", true))
    sw.WriteLine("李四 90");
// score.txt → "张三 85\n李四 90"

new StreamWriter("文件名") → 覆盖写入，从头写

new StreamWriter("文件名", true) → 追加写入，原有内容保留

StreamReader — 读取文件

同样用 using 包裹，两种读法：

CSHARP
// 逐行读取
using (StreamReader sr = new StreamReader("score.txt"))
{
    string line;
    while ((line = sr.ReadLine()) != null)   // 读到 null 表示文件结束
        Console.WriteLine(line);
}

// 一次性读取全部
using (StreamReader sr = new StreamReader("score.txt"))
{
    string all = sr.ReadToEnd();
    Console.WriteLine(all);
}
  • ReadLine() → 读一行，文件结束返回 null
  • ReadToEnd() → 一次性读完全部

File 类 — 一行搞定读和写

StreamReader/Writer 灵活但步骤多。File 类提供快捷方法：

CSHARP
using System.IO;

// 写入：一行搞定
File.WriteAllText("hello.txt", "Hello World");

// 读取：一行搞定
string content = File.ReadAllText("hello.txt");
Console.WriteLine(content);  // Hello World

// 按行读（返回数组，每个元素一行）
string[] lines = File.ReadAllLines("score.txt");
foreach (string line in lines)
    Console.WriteLine(line);

// 按行写
string[] names = { "张三", "李四", "王五" };
File.WriteAllLines("names.txt", names);

// 追加一行
File.AppendAllText("log.txt", "程序启动\n");
方法作用
File.WriteAllText(路径, 内容)写入文本（覆盖）
File.ReadAllText(路径)读取全部文本
File.WriteAllLines(路径, 数组)按行写入（覆盖）
File.ReadAllLines(路径)按行读取，返回数组
File.AppendAllText(路径, 内容)追加文本
File.Exists(路径)判断文件是否存在

异常处理 — try-catch

上了用了 File.ReadAllText() 读文件，但如果文件压根不存在呢？程序直接崩——C# 会在出错时生成一个 Exception 对象（装着错误信息），没人拦截它就一路抛到最外层，程序闪退。

不想让它崩？用 try-catch 兜住：try 里放可能出错的代码，catch 里写怎么善后。

CSHARP
try
{
    string content = File.ReadAllText("data.txt");   // 尝试读取
    Console.WriteLine(content);
}
catch (FileNotFoundException)                        // 文件不存在
{
    Console.WriteLine("文件没找到！请检查路径");
}
catch (Exception ex)                                 // 其他所有错误
{
    Console.WriteLine($"出错了：{ex.Message}");
}

常见的文件异常类型，按具体→笼统的顺序写：

catch 类型捕获场景
FileNotFoundException文件不存在
DirectoryNotFoundException文件夹不存在
IOException读写失败（被占用、无权限等）
Exception兜底——上面没匹配到的全归它
💡 你还可以主动 throw 异常——在自己的方法里发现不合理参数时抛出去，让调用者用 try-catch 兜住：
CSHARP
void Withdraw(double amount)
{
    if (amount <= 0)
        throw new ArgumentException("取款金额必须大于0");
    if (amount > balance)
        throw new InvalidOperationException("余额不足");
    balance -= amount;
}

调用方用 try-catch 接住：

CSHARP
try
{
    Withdraw(-100);
}
catch (ArgumentException ex)
{
    Console.WriteLine($"参数错误：{ex.Message}");
}
catch (InvalidOperationException ex)
{
    Console.WriteLine($"操作失败：{ex.Message}");
}

还有 finally——不管 try 里出不出事，finally 里的代码一定执行。典型场景是关闭文件：

CSHARP
StreamReader sr = null;
try
{
    sr = new StreamReader("data.txt");
    Console.WriteLine(sr.ReadToEnd());
}
catch (FileNotFoundException)
{
    Console.WriteLine("文件不存在");
}
finally
{
    sr?.Close();                     // 不管怎样都关文件
    Console.WriteLine("文件已关闭");
}
💡 用了 using 就基本不需要手写 finally——它自动帮你调用 Close()，等价于上面整个 try-catch-finally。
🤖 AI 定位异常根因：程序崩了别慌——把完整的异常信息（类型 + 消息 + 堆栈跟踪）贴给 AI，它能帮你快速定位是哪一行、什么原因。但修好代码后必须用课件7教的调试技巧自己走一遍，确保真的修好了。

课堂练习1 — 成绩单工具

输入学生成绩保存到文件，再读取计算平均分——一次练写和读。

期望输入：

代码示例（老师示范讲解）

姓名：张三，成绩：85
姓名：李四，成绩：90  
姓名：王五，成绩：78
姓名：q（结束）

期望输出：

张三：85分
李四：90分
王五：78分
平均分：84.3
CSHARP
using System.IO;

// ① 输入成绩，追加到文件
using (StreamWriter sw = new StreamWriter("scores.txt", true))
{
    while (true)
    {
        Console.Write("姓名（输入 q 结束）：");
        string name = Console.ReadLine();
        if (name == "q") break;

        Console.Write("成绩：");
        int score = int.Parse(Console.ReadLine());
        sw.WriteLine($"{name} {score}");
    }
}
  • 动手：把 true 去掉，观察第二次运行时之前的成绩还在不在
💬 解释说明
  • new StreamWriter(file, true) 的 true = 追加模式，旧数据保留
  • 不加 true = 覆盖模式，每次运行清空文件重写
  • File.Exists() 判断文件是否存在，避免读不存在的文件崩掉

综合练习 — 简易通讯录

通讯录存入文件，支持添加、显示全部、按姓名查找——File 类 + 菜单循环综合应用。

期望输入：

1（添加）→ 张三 13800138000
1（添加）→ 李四 13900139000
2（全部显示）
3（查找）→ 张三
4（退出）

期望输出：

张三：13800138000
李四：13900139000
张三：13800138000（查找结果）
  • File.AppendAllText(文件, 内容) 追加一行，自动处理关闭
  • File.ReadAllLines(文件) 读全部行返回数组
  • File.Exists(文件) 判断文件是否存在，读/查前先判断
  • 查找用 line.StartsWith(关键词)

CSHARP
using System.IO;

string file = "contacts.txt";

while (true)
{
    Console.WriteLine("\\n1.添加  2.全部显示  3.查找  4.退出");
    string choice = Console.ReadLine();

    if (choice == "1")
    {
        Console.Write("姓名：");
        string name = Console.ReadLine();
        Console.Write("电话：");
        string phone = Console.ReadLine();
        File.AppendAllText(file, $"{name},{phone}\\n");
        Console.WriteLine("已保存");
    }
    else if (choice == "2")
    {
        if (!File.Exists(file)) continue;
        foreach (string line in File.ReadAllLines(file))
        {
            string[] parts = line.Split(',');
            Console.WriteLine($"{parts[0]}：{parts[1]}");
        }
    }
    else if (choice == "3")
    {
        Console.Write("查找姓名：");
        string search = Console.ReadLine();

        {
            if (line.StartsWith(search))
            {
                string[] parts = line.Split(',');
                Console.WriteLine($"{parts[0]}：{parts[1]}");
            }
        }
    }
    else break;
}

拔高题（选做，自己写，不填空）

需求：自己用 StreamReader 打开一个文本文件，逐行读取并统计：总行数、以及所有行的总字符数（不含换行）。
要求：自己写循环读取，不依赖 File.ReadAllLines 一次性读入。
CSHARP
int lines = 0, chars = 0;
using (StreamReader sr = new StreamReader("data.txt"))
{
    string line;
    while ((line = sr.ReadLine()) != null)
    {
        lines++;
        chars += line.Length;
    }
}
Console.WriteLine($"共 {lines} 行，{chars} 个字符");
