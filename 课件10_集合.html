数组的局限性

数组很好用，但有三个死穴：

CSHARP
int[] scores = { 85, 90, 78 };   // 3个元素
scores[3] = 92;    // ❌ 越界！不能往里面加第4个
局限说明
大小固定创建后不能增删元素
没有查找方法Contains("张三") 不支持
没有删除方法想删"第2个学生"？只能手动移位
  • 解决方案：C# 提供了集合——动态可增长的数据容器

List<T> — 动态数组

List 就像一个会自动变长的数组。数组创建后大小就固定了，不能加人也不能删人；List 可以随时增删元素，长度自动跟着变。

数组List<T>
大小创建时固定随时增删，自动扩容
增删❌ 不支持✅ Add / Remove
查找❌ 手写循环✅ Contains 直接查
遍历for / foreachfor / foreach（完全一样）
List 不是 C# 自带的，存放在集合库里，需要先引入：
CSHARP
using System.Collections.Generic;  // 引入集合库

System.Collections.Generic 是集合库的"地址"，using 就是告诉程序"我要用这里的工具"（课件2讲过 using System 同理）。

CSHARP
// 数组的写法：类型[] 变量名
int[] arr = new int[5];

// List 的写法：List<类型> 变量名
List<int> scores = new List<int>();
//      ↑ 尖括号里的 int 和数组的 int[] 一样，都是指定"装什么类型"
  • List<T> 的 T 就是个占位符，用的时候换成具体类型：List<int>、List<string>
  • 不需要指定大小，会自动扩容
CSHARP
scores.Add(85);   // 往末尾追加
scores.Add(90);
scores.Add(78);
scores[1] = 95;   // 改元素，和数组一样用 []

List 常用操作

操作数组List<T>
获取数量arr.Lengthlist.Count
访问元素arr[0]list[0]
增❌Add() Insert()
删❌Remove() RemoveAt()
查找❌Contains()
CSHARP
List<string> names = new List<string> { "张三", "李四", "王五" };

// Add：追加
names.Add("赵六");

// Insert：指定位置插入
names.Insert(0, "赵六");

// Remove：按值删除
names.Remove("李四");

// RemoveAt：按索引删除
names.RemoveAt(0);

// Contains：检查是否包含
if (names.Contains("张三")) { ... }

// Count：元素个数（注意是 Count，不是 Length）
Console.WriteLine($"共 {names.Count} 人");

List 创建与遍历

CSHARP
// 方式1：new + 初始化（最常用）
List<int> scores = new List<int> { 85, 90, 78, 88, 92 };

// 方式2：空列表，逐个添加
List<string> names = new List<string>();
names.Add("张三"); names.Add("李四");

// 方式3：数组转 List
int[] arr = { 85, 90, 78 };
List<int> scores2 = new List<int>(arr);

遍历——for 和 foreach 都可以：

CSHARP
for (int i = 0; i < scores.Count; i++)
    Console.WriteLine(scores[i]);

foreach (int s in scores)
    Console.WriteLine(s);

课堂练习1 — List 学生管理

用 List<string> 管理学生名单：新增、删除、查找，体会和数组的区别。

代码示例（老师示范讲解）

CSHARP
List<string> students = new List<string> { "张三", "李四", "王五" };

students.Add("赵六");
Console.WriteLine($"新增后共 {students.Count} 人");

students.RemoveAt(1);    // 删除第2个
Console.WriteLine("删除后：");
foreach (string name in students)
    Console.WriteLine($"  {name}");

Console.Write("查找谁？");
if (students.Contains(Console.ReadLine()))
    Console.WriteLine("在列表中！");
else
    Console.WriteLine("不在列表中");
  • 动手：加上"修改姓名"和"在第1位插入"功能
💬 解释说明
  • List<T> 不用指定大小，Add() 往末尾加，Count 自动更新
  • RemoveAt(索引) 按位置删，Contains() 检查是否存在——数组没有这两个
  • 增删改查都比数组方便，这就是 List 的价值

Dictionary — 键值对

Dictionary<K,V> 是另一种集合，它不用编号找人，而是用名字找人。就像查字典——查"Apple"得到"苹果"，查"张三"得到 85 分。

  • 左边的叫键（Key），右边的叫值（Value），合起来叫键值对
  • 键是唯一的，不能重复；值可以重复
List（按编号找）：          Dictionary（按名字找）：
[0] → "张三"                "张三" → 85 分
[1] → "李四"                "李四" → 90 分
[2] → "王五"                "王五" → 78 分

<K,V> 里为什么有两个类型？

List<T> 只有一个占位符（装什么类型），Dictionary<K,V> 有两个——K 管键的类型，V 管值的类型：

CSHARP
List<string> names;              // 一个 T：装什么
Dictionary<string, int> scores;  // K=键的类型, V=值的类型
//              ↑键      ↑值
//          "张三"  →  85
//          "李四"  →  90
K 和 V 不限于 string → int，可以是任意类型的组合——Dictionary<int, string>（学号→姓名）、Dictionary<string, bool>（姓名→是否及格）都行。

代码创建：

CSHARP
using System.Collections.Generic;

Dictionary<string, int> scores = new Dictionary<string, int>();

scores["张三"] = 85;     // 添加键值对
scores["李四"] = 90;
scores["王五"] = 78;

Console.WriteLine(scores["张三"]);   // 85 — 按键取值

Dictionary 常用操作

操作代码说明
增/改dict["键"] = 值键不存在→新增，键已存在→覆盖（同一个语法）
删dict.Remove("键")按键删除，键不存在也不会报错
查先 dict.ContainsKey("键") 再 dict["键"]先判断再取值，避免键不存在时报错
遍历foreach (var kv in dict)kv.Key 取键，kv.Value 取值
CSHARP
Dictionary<string, int> scores = new Dictionary<string, int>
{
    { "张三", 85 }, { "李四", 90 }, { "王五", 78 }
};

// 改值（和数组一样 = 赋值）
scores["王五"] = 80;

// 删：Remove
scores.Remove("李四");

// 查：先用 ContainsKey 检查键是否存在，避免报错
if (scores.ContainsKey("张三"))
    Console.WriteLine(scores["张三"]);
else
    Console.WriteLine("查无此人");

// 遍历所有键值对
foreach (var kv in scores)
    Console.WriteLine($"{kv.Key}: {kv.Value}分");
    // kv.Key = 键（如"张三"），kv.Value = 值（如85）

本节知识梳理

今天我们一起啃下了这些核心内容：

  • 数组的局限性：长度固定、增删麻烦
  • List<T> — 动态数组：List<int> 长度可随用随长
  • List 常用操作：Add 加、Remove 删、Count 数个数、Contains 查存在
  • List 创建与遍历：new List<T>() 或 new(){...}，for/foreach 遍历
  • Dictionary — 键值对：Dictionary<K,V> 用「键」查「值」，像字典
  • Dictionary 常用操作：Add 加、[键] 取、ContainsKey 判断键是否存在

综合练习 — 购物车

用 Dictionary 实现购物车：商品名→数量，支持添加、查看、删除。

期望输入： 交互输入（见运行效果）

期望输出：

1.添加  2.查看  3.删除  4.退出
1
商品名：苹果
数量：3
已添加：苹果 ×3
2
苹果 ×3
  • cart[商品名] = 数量 — 增/改都用这个语法
  • cart.Remove(商品名) 删除，foreach (var kv in cart) 查看
  • while 循环 + switch/if 实现菜单交互
  • ___ 是需要你补全的地方

CSHARP
Dictionary<string, int> cart = new Dictionary<string, int>();

while (true)
{
    Console.WriteLine("\n1.添加  2.查看  3.删除  4.退出");
    string choice = Console.ReadLine();

    if (choice == "1")
    {
        Console.Write("商品名：");
        string item = Console.ReadLine();
        Console.Write("数量：");
        int qty = int.Parse(Console.ReadLine());
        cart[item] = qty;
    }
    else if (choice == "2")
        foreach (var kv in cart)
            Console.WriteLine($"{kv.Key} ×{kv.Value}");
    else if (choice == "3")
    {
        Console.Write("删除商品：");
        cart.Remove(Console.ReadLine());
    }
    else break;
}

拔高题（选做，自己写，不填空）

需求：让用户输入若干个整数（逗号分隔），用 List 存储并去掉重复，输出去重后的列表。
要求：自己写——拆分、转换、遍历判断是否已存在再添加，不能用 Distinct()。
CSHARP
string input = Console.ReadLine();
List<int> list = new List<int>();
foreach (string p in input.Split(','))
{
    int v = int.Parse(p.Trim());
    if (!list.Contains(v)) list.Add(v);
}
foreach (int v in list) Console.Write(v + " ");
