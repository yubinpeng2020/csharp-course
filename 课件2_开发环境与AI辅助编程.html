搭建开发环境

搭环境 = 装两样：.NET SDK（运行平台）+ VS Code（编辑器）

① 下载 .NET SDK

  • 访问 https://dotnet.microsoft.com/download ，选择 ".NET SDK x64" 下载（也可使用老师提供的安装包）

② 安装 .NET SDK

  • 运行安装程序，点击"安装"

③ 安装完成

  • 安装完成，点击"关闭"

④ 打开命令提示符

  • Win+R → 输入 cmd → 回车

⑤ 验证安装

  • 输入 dotnet --version，输出版本号即安装成功
只有 .NET 10+ 支持在没有项目文件的情况下直接调试 .cs 文件。

⑥ 下载 VS Code

  • 访问 https://code.visualstudio.com/ ，点击"Download for Windows"

⑦ 同意许可协议

  • 同意许可协议，点击"下一步"

⑧ 选择安装路径

  • 选择目标位置，点击"下一步"

⑨ 选择开始菜单

  • 选择开始菜单文件夹，点击"下一步"

⑩ 选择附加任务

  • 勾选附加任务（建议全选），点击"下一步"

⑪ 确认安装

  • 确认安装信息，点击"安装"

⑫ 安装完成

  • 安装完成，点击"完成"

⑬ 安装 C# 扩展

  • 打开 VS Code，按 Ctrl+Shift+X 进入扩展栏
  • 搜索 "C# Dev Kit"，点击 install 安装

⑭ 打开项目文件夹

  • 在E盘新建一个文件夹（如 code）
  • 重启 VS Code → File → Open Folder 打开该文件夹

⑮ 新建文件

  • 在左侧文件目录右键 → New File

⑯ 命名文件

  • 命名为 test.cs

⑰ 编写代码

  • 复制以下示例代码粘贴到编辑区
CSHARP
using System;
namespace HelloWorld
{
    class Program
    {
        static void Main()
        {
            Console.WriteLine("你好，C#！");
            Console.ReadKey();
        }
    }
}

⑱ 运行程序

  • 点击右上角 ▶ "运行"按钮，查看输出结果
💡 以后写代码都在这套环境里：新建 .cs 文件 → 写代码 → 点运行。VS Code + C# Dev Kit 已包含智能提示和调试功能。

运行程序与常见问题

运行方式

在 VS Code 中写好代码后，任选其一：

  • ▶ 点击右上角运行按钮
  • F5 按键盘 F5 键
  • 菜单 运行 → 启动调试
✅ 终端显示输出结果 → 成功！

常见问题

Q: 终端一闪而过，看不到输出？

在 Main() 末尾加一行：Console.ReadKey();

Q: 中文输出乱码？

在文件开头加：Console.OutputEncoding = System.Text.Encoding.UTF8;

Q: 运行按钮灰色、点不了？

确保 VS Code 右下角状态栏显示"C# Dev Kit 已激活"，否则重启 VS Code。

Q: 提示"找不到 .NET SDK"？

打开终端输入 dotnet --version 检查是否安装了 SDK。

理解程序代码与结构

⚠️ 先记住这件事：现阶段，你的代码就写在这个骨架的 Main() 里。

C# 程序的基本骨架（记住它！）

CSHARP
using System;                   // 工具箱

namespace HelloWorld            // 命名空间
{
    class Program               // 程序类
    {
        static void Main()      // ← 入口：代码从这儿开始运行
        {
            // 你的代码写在这里！
        }
    }
}

然后加上两行功能代码，就成了刚才运行的完整程序：

CSHARP
using System;
namespace HelloWorld
{
    class Program
    {
        static void Main()
        {
            Console.WriteLine("你好，C#！"); // ⑤ 输出
            Console.ReadKey();             // ⑥ 防闪退
        }
    }
}
行关键词作用必须？
①using System引入系统工具包✅
②namespace组织代码，像文件夹可省略
③class定义程序，{ } 包裹✅
④static void Main()程序入口，首字母大写✅
⑤Console.WriteLine()打印文字到屏幕按需
⑥Console.ReadKey()等按键再关闭初学建议加
  • 语句以分号 ; 结束，代码块用 { } 包裹

常见问题：

  • 窗口一闪而过？→ 末尾加 Console.ReadKey();
  • 中文乱码？→ 开头加 Console.OutputEncoding = System.Text.Encoding.UTF8;

注释

注释是对代码的解释说明，编译器会忽略它，不影响程序运行。

① 单行注释 //

CSHARP
// 从 // 开始到本行结束，都是注释
int age = 18;   // 也可以写在代码后面
  • 最常用，对当前行或下一行做简短说明
  • 写在自己的代码旁边，解释"这行在干嘛"

② 多行注释 /* */

CSHARP
/*
   需要写很多行说明时用这个
   中间不管多少行，全都是注释
*/
int score = 95;  // 这行不在注释里，会正常执行
  • 从 /* 开始，到 */ 结束，中间全是注释
  • 适合写长段解释，或临时禁用一段代码（调试时常用）

③ 文档注释 ///

CSHARP
/// <summary>
/// 计算两个数的和
/// </summary>
/// <param name="a">第一个数</param>
/// <param name="b">第二个数</param>
/// <returns>和</returns>
static int Add(int a, int b) { return a + b; }
  • 在类或方法前输入 /// 自动生成模板
  • 鼠标悬停时 VS Code 会显示这段说明（智能提示）
类型写法什么时候用
单行//简短说明，日常最常用
多行/* */长段解释 / 临时禁用代码
文档///给方法写"使用说明书"
💡 养成写注释的习惯：别人能看懂，未来的自己也能看懂。
课堂上有老师教，但课后自己练的时候难免卡住。别急——让 AI 成为你的专属编程助教，随时问、随时学。

AI时代，学编程还有意义吗？

需要。而且比以前更需要。 AI 是你的副驾驶，不是代驾——方向盘始终在你手里。看不懂路、不会判断方向，AI 再强也没用。

会编程 vs 只靠 AI，差距有多大？

如果只靠 AI如果你会编程
复制粘贴，跑不动就懵了能看懂报错，自己定位问题
AI 给错方案，你不知道能判断 AI 给的代码合不合理
换个类似问题就不会了掌握了原理，什么场景都能应对
永远依赖工具工具为你所用，效率翻倍
核心观点：AI 能给你答案，但问不出好问题，答案就是废的。下一页告诉你具体怎么做。

正确使用 AI

用好 AI 的前提是：先搞清什么不能做。

这些错误做法，你中了几条？

场景❌ 不要这样✅ 应该这样
不会写代码"帮我写个XX功能"先自己列需求，写个大概，再让AI补充
AI给出代码复制粘贴，能跑就行逐行理解，要求AI解释每行含义
遇到报错直接复制报错问AI先自己看报错信息，找到关键行，再问AI
代码跑通了交作业 / 不再看了回去看AI的代码和自己写的有什么不同

AI 能帮你做什么？

能力说明你的态度
🧠 代码生成根据描述生成代码片段参考，不照搬
📖 代码解释解释复杂代码的逻辑学了要能自己讲
🐛 错误排查分析报错信息，定位问题先自己看，再问
📚 学习辅助提供学习路线和资料执行，不收藏
⚡ 效率提升写测试、重构、生成文档趁早学会

记住这个四步法

  1. 先思考 💭：遇到问题自己分析，尝试解决（至少 5 分钟）
  2. 再求助 🤝：带着自己的分析去问 AI，不是空手提问
  3. 必须懂 🧠：拿到 AI 的答案后，要求解释，直到能自己复述
  4. 自己写 ✍️：关掉 AI，独立重写一遍，对比差异
判断标准：能向老师讲清楚这段代码 = 真的会了

❓ 怎么提问

差的提示词 = 反复返工；好的提示词 = 一次到位。

对比一下：

❌ 模糊版（不好）：

帮我写个排序程序

✅ 精准版（好）：

你是一位C#编程助教，擅长用简单的语言讲解代码。
请用C#写一个冒泡排序程序：
1. 输出完整的可运行代码
2. 为每一行添加注释，说明作用
3. 在关键位置用 Console.WriteLine 打印排序过程
提示词三要素：🎭 角色 + 🎯 任务 + 📋 输出约束

对照精准版，看看三要素分别对应哪一步：

要素含义示例（取自精准版）
🎭 角色告诉 AI「你是谁」"你是一位C#编程助教"
🎯 任务告诉 AI「做什么」"用C#写一个冒泡排序"
📋 输出约束告诉 AI「输出什么格式」"注释 + 打印排序过程"
💡 三要素缺一个，AI 输出质量都会明显下降。

AI辅助实操 — 获取与验证

第1步：拿到代码并运行

用上一页的提问公式问 AI，它会生成完整的冒泡排序程序。AI 通常返回类似这样的代码：

CSHARP
using System;
class Program
{
    static void Main()
    {
        int[] arr = { 5, 2, 8, 1, 9 };      // 待排序的数组
        Console.WriteLine("排序前：" + string.Join(", ", arr));

        // 冒泡排序
        for (int i = 0; i < arr.Length - 1; i++)
        {
            for (int j = 0; j < arr.Length - 1 - i; j++)
            {
                if (arr[j] > arr[j + 1])     // 如果前一个数大于后一个
                {
                    int temp = arr[j];        // 交换两个数
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
            Console.WriteLine($"第{i + 1}轮：" + string.Join(", ", arr));  // 打印每轮结果
        }

        Console.WriteLine("排序后：" + string.Join(", ", arr));
    }
}
先在 VS Code 里跑一遍，确认程序能运行、输出正确。再继续下一步。
不算——你还没真正理解代码。接下来追问 AI，直到能自己讲清楚。

第2步：追问与消化

追问示例 ① — 问原理

为什么需要两层 for 循环？能不能用一层循环实现？

AI 会解释外层控制轮数、内层比较相邻元素，帮你理解算法逻辑。

追问示例 ② — 问变通

怎么改成从大到小（降序）排序？

AI 把 > 改成 <，并解释为什么这样就能反过来排。

AI 不是问一次就结束的——不满意就让它重来，有疑问就接着追问。

第3步：自己动手

  1. 修改数据：把数组改成 { 10, 3, 7, 1, 6 }，观察输出变化
  2. 关掉 AI，独立重写：不看 AI 的代码，自己从头写一遍
  3. 对比差异：自己写的 vs AI 给的，逻辑一样吗？
