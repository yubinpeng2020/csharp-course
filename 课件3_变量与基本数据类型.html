什么是变量？

  • 类比：变量就像贴了标签的盒子
  • 盒子的类型决定能放什么：整数盒、小数盒、文字盒
  • 盒子上有标签（变量名）：age、name、score
  • 盒子里装东西（值）：18、"张三"、95.5
  • 变量 = 一块有名字的内存空间，程序运行时值可以改变
  • 必须先声明再使用
代码中长这样（语法后面页面详讲）：
（盒子的类型 → 类型） （标签 → 标识符） = （东西 → 值）
CSHARP
  int    age    =    18;          // 类型  标识符  等号  值 → 整数盒子
  string name   =    "张三";       // 类型  标识符  等号  值 → 文字盒子
  double score  =    95.5;        // 类型  标识符  等号  值 → 小数盒子

标识符

标识符：程序中给变量、方法、类等起的名字，就像给每个人起名字一样

  • ✅ 规则：字母或下划线开头，由字母、数字、下划线组成
  • ❌ 不能：数字开头、含空格
  • 区分大小写：age和Age是两个不同变量
  • 用有意义的英文单词：studentName ✅ 不用 a、x ❌
CSHARP
int age = 18;              // age 是标识符（你起的名字）
string studentName = "张三"; // studentName 是标识符
在编辑器中，标识符和关键字会显示不同颜色——一眼就能区分系统规定的词和你的自定义名称
💡 复制代码到 VS Code 后如果缩进乱了，右键选择 Format Document（或按 Shift + Alt + F）一键格式化

常用数据类型概览

类型类别字节数位数有效数字说明示例
int整数432—整数，最常用int age = 18;
double小数86415~16位双精度小数double pi = 3.14;
float小数4327位单精度小数float price = 9.9f;
decimal小数1612828~29位高精度（财务用）decimal m = 1.12m;
bool布尔18—真或假bool ok = true;
char字符216—单个字符char g = 'A';
string字符串不定不定—文本string n = "张三";
bit（位）是计算机存储的最小单位，每个位只能表示 0 或 1。8 个 bit 组成 1 个字节。就像用厘米量高度，字节是度量数据大小的"单位"。
精度指小数点后能保留多少位有效数字：float（约7位）< double（约15位）< decimal（约28位）。日常计算用double足够，算钱用decimal。
位数决定了能存储多少种状态。4字节（32位）有 2³² ≈ 42亿种组合，8字节（64位）有 2⁶⁴ ≈ 1844亿亿种——更大的"空间"能表示更多小数位，精度自然更高。就像一张纸越大，能写的小数位数越多。

整数类型详解

类型范围字节数说明
byte0~2551无符号8位
sbyte-128~1271有符号8位
short-32768~327672有符号16位
int-21亿~21亿4最常用
long±9×10¹⁸8超大整数
  • 日常编程99%用int就够了
  • 需要超大数字时用long：long bigNum = 10000000000L;
1 字节 = 8 位，每位的 0/1 有 2 种可能，8 位共有 2⁸ = 256 种组合。从 0 开始编号，就是 0~255。（sbyte 用最高位表示符号：0 表示正数，1 表示负数，所以也是 256 种组合，拆分为 -128~127）

整数的不同写法（进制）

  • 同一数值可以用不同进制表示：
CSHARP
  int a = 255;          // 十进制（默认，日常用）
  int b = 0xFF;         // 十六进制（0x/0X开头）
  int c = 0b11111111;   // 二进制（0b/0B开头）
  // 三个变量值是相同的，都是 255

进制快速转换

进制前缀可用字符场景
十进制无0-9日常编程
十六进制0x0-9、A-F（代表10-15）颜色值、内存地址
二进制0b0、1位运算、底层操作
  • 颜色值 #FF5733 → C# 中写作 0xFF5733
  • 十六进制每 1 位 = 二进制 4 位：F = 1111，FF = 11111111

十进制 → 二进制：除以2，取余数，倒序排列

例：13 转二进制
13 ÷ 2 = 6 ... 余1
 6 ÷ 2 = 3 ... 余0
 3 ÷ 2 = 1 ... 余1
 1 ÷ 2 = 0 ... 余1
          ↓ 倒序：1101
∴ 13 = 0b1101

二进制 → 十六进制：每4位一组（8421法）

0b 1101 1010
    ↓    ↓
   8+4+0+1  8+0+2+0
   =13     =10
   =D      =A
∴ 0b11011010 = 0xDA
CSHARP
// C#中直接写就行，编译器自动认
int x = 0b1101;   // 13
int y = 0xDA;     // 218
记不住没关系——编程时很少手算，C#会自动处理。关键是认识写法。
1 字节 = 8 位二进制，最大 11111111 = 十进制 255 = 十六进制 0xFF。进制和字节是同一回事的不同写法。

类型精度占用后缀示例
float7位4字节必须加ffloat x = 3.14f;
double15-16位8字节默认（可加d）double y = 3.14;
decimal28位16字节必须加mdecimal z = 1.12m;
  • float和decimal后缀不能忘：不加会报错
  • 日常小数用double，金额计算用decimal
位数决定了能存储多少种状态。4字节（32位）有 2³² ≈ 42亿种组合，8字节（64位）有 2⁶⁴ ≈ 1844亿亿种——更大的"空间"能表示更多小数位，精度自然更高。就像一张纸越大，能写的小数位数越多。

bool类型

  • 只有两个值：true（真）或false（假）
  • ⚠️ C#中不能用1和0代替true/false
CSHARP
  bool isPass = true;    // ✅ 正确
  bool flag = 1;         // ❌ 错误！C#不允许
  bool flag = false;     // ✅ 正确
  • 典型应用：标记状态、条件判断（后续讲）

char类型

  • 表示单个字符，用单引号括起来
CSHARP
  char grade = 'A';
  char digit = '7';
  char letter = '张';    // 中文字符也可以
  • 特殊字符需要转义：
转义符含义
\n换行
\t制表符（Tab）
\\反斜杠自身
\"双引号
\'单引号

string类型

  • 表示一串字符（0个或多个），用双引号括起来
  • string 本质上是 char 组成的序列："ABC" = 'A' + 'B' + 'C'
CSHARP
  string name = "张三";
  string empty = "";          // 空字符串（允许）
  string path = "C:\\Users\\";  // 用\\表示路径中的\
  string path2 = @"C:\Users\";  // @前缀，原样输出，更简洁
  • 字符串拼接用+：
CSHARP
  string greeting = "你好，" + name;
  • $ 插值写法（推荐，更简洁）：
CSHARP
  string name = "张三";
  int age = 18;
  string greeting = $"你好，{name}";
  Console.WriteLine($"姓名：{name}，年龄：{age}");

变量的声明与赋值

  • 声明格式：数据类型 变量名;
  • 赋值：把值放进变量
CSHARP
  int age;           // 声明：告诉计算机"我要一个装整数的盒子"
  age = 18;          // 赋值：把18放进去

  string name = "张三";  // 声明 + 赋值一步到位（推荐）
  double score = 95.5;
  bool isStudent = true;
  • 多变量同时声明：int a = 1, b = 2, c = 3;
  • 变量必须先声明后使用

var 类型推断

  • 让编译器自动判断类型：
CSHARP
  var name = "张三";       // 编译器推断为 string
  var age = 18;            // 编译器推断为 int
  var price = 9.99;        // 编译器推断为 double
  var flag = true;         // 编译器推断为 bool
  • 规则：
  • ✅ 声明时必须初始化（不给值没法推断）
  • ✅ 类型一旦确定就不能更改
  • ❌ 不能用于类的字段（只能局部变量）
CSHARP
  var x = 10;
  x = "hello";    // ❌ 错误！x 已经推断为 int
  var y;          // ❌ 错误！没有初始化

命名规范

C# 有不同的命名风格，不同场景用不同规范：

命名法规则适用场景示例
Pascal每个单词首字母大写类名、方法名、接口名Student、GetStudentName、ICompare
Camel首单词小写，其余首字母大写变量名、参数名studentName、totalScore
全大写所有字母大写，下划线分隔常量名PI、MAX_VALUE
命名规范不是编译器强制的——写 studentname 照样能运行。但好的命名是程序员的素养，让别人（和未来的自己）一眼看懂代码。

常量

  • 值在运行期间不可改变
CSHARP
  const double PI = 3.14159;
  const string SCHOOL = "汕头职业技术学院";
  • 命名规范：全大写 + 下划线分隔（回顾命名规范）
  • 为什么用常量？看一个场景：
CSHARP
  // 快递费按 8 元计算，代码里写了 20 个地方
  // 一个月后快递费涨到 10 元……
  // 你要一个个找出来改，漏一个就出错！
  
  // 用常量就没有这种烦恼：
  const double EXPRESS_FEE = 8;
  // 所有地方都写 EXPRESS_FEE，改一处，全部生效 ✅
  • 核心好处：一改全改 + 含义直观（PI 比 3.14159 好懂）
  • ⚠️ const变量必须在声明时赋值，之后不能修改
变量用 int x = 5; 声明，值可以改（x = 10;）。常量用 const int X = 5; 声明，值一旦设定就不能改（X = 10; 会报错）。常量的好处是"一改全改"，适合不会变的值如税率、圆周率。

变量的作用域

先快速认识程序的基本骨架：

CSHARP
class Program                          // 类：程序的"容器"
{
    static void Main()                 // Main方法：程序的"入口"
    {                                  // ← 花括号定义了一个"作用域"
        // 你的代码写在这里
    }
}
  • 变量只在定义它的 { } 范围内有效——这就是作用域
CSHARP
  {
      int a = 10;
      Console.WriteLine(a);   // ✅ a 在这里有效
  }
  //Console.WriteLine(a);     // ❌ 出了大括号，a 不存在了
  • 规则：变量只在包含它的最近一对 { } 内有效。出了这个范围，变量就"消失了"。

基础输入输出 — Console

  • Console 是 C# 提供的控制台类，负责程序和屏幕/键盘之间的交互
  • 回顾：Console.Write() / Console.WriteLine() 向屏幕输出
  • 新知识：Console.ReadLine() 从键盘读入用户输入：

  请输入你的名字：张三

课堂练习1 — 变量与输入输出

动手试：声明变量、读入用户输入、做简单运算并输出。

代码示例（老师示范讲解）

CSHARP
class Program
{
    static void Main()
    {
        Console.Write("请输入第一个数：");
        double x = double.Parse(Console.ReadLine());   // 读入并转成 double

        Console.Write("请输入第二个数：");
        double y = double.Parse(Console.ReadLine());

        double sum = x + y;          // 把两数加起来
        Console.WriteLine($"两数之和 = {sum}");
    }
}
  • 动手：把 double 改成 int 再运行一次，观察整数除法差异

  • Console.ReadLine() 返回 string，要当数字用必须 double.Parse() 转换
  • 变量先声明、后赋值、再使用，类型要和存的值一致

本节知识梳理

今天我们一起啃下了这些核心内容：

  • 什么是变量？：变量是内存里一块带名字的盒子，用来存数据，取值可改
  • 常用数据类型（整数 / 浮点 / bool / char / string）：整数存整数、浮点存小数、bool 存真假、char 存单字符、string 存文本
  • 变量的声明与赋值：类型 名字 = 值; 先声明类型再给初值
  • var 类型推断：var x = 10; 编译器自动推断类型，写起来更省事
  • 常量：const double PI = 3.14; 一旦赋值不能再改
  • 变量的作用域：变量在哪对 {} 里声明，就只能在哪用，出了范围访问不到
  • 基础输入输出 — Console：Console.ReadLine() 读输入、Console.WriteLine() 写输出
💡 接下来是「综合练习」——不再是单个知识点的小练习，而是把上面这些串起来解决一个真实小任务。先自己动手写，实在卡住再看答案。
